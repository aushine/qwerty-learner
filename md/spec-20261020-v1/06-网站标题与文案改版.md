## 一、背景与目标

当前 `index.html` 标题为：

```
Qwerty Learner 官网 — 为键盘工作者设计的单词与肌肉记忆锻炼软件
```

该文案只覆盖了**学习模式（单词记忆）**，而项目现状已扩展为三块能力：

- **学习模式**（Qwerty Learner）：单词记忆 + 默写 + 词库；
- **打字模式**（Typing Learner）：全拼/双拼对码练习 + 打字测速（上屏轨）；
- **打字游戏中心**：墨雨·落字成画 / 诗词射击 / 成语接龙（`spec-20261019-v1`）。

需求提出方原话「我暂时没想好，你根据目前我们的项目现状帮我设计几个供我选择」——本文档给出 **5 个候选标题**及配套 SEO 字段方案，选定后施工。

**成功标准**：需求方从候选（或自定义）中选定 1 个；`index.html` 的 title / og / twitter / description / keywords 全字段一致更新；构建产物生效；产品名「Qwerty Learner」本身不变。

## 二、设计约束

1. **品牌名不变**：产品名 `Qwerty Learner` 保留（manifest、`application-name`、结构化数据 `name`、仓库名均不改）。
2. **长度**：中文 title 建议 ≤ 30 个汉字（搜索结果约截断 30 字），关键词前置。
3. **覆盖三能力**：新文案应体现「单词记忆 × 打字练习 × 打字游戏」的现状，不再只讲英语学习。
4. **关键词可检索**：保留「打字练习 / 背单词 / 键盘工作者」等既有有效词（keywords 已在见效，不清塘），增量补「双拼 / 打字测速 / 打字游戏 / 中文打字」。
5. **官网定位保留**：「官网」字样可按候选取舍；OG/Twitter 卡片文案与 title 联动。

## 三、候选方案（待选 1）

| 候选 | 标题文案 | 风格 | 优点 | 代价 |
| --- | --- | --- | --- | --- |
| **A（最小改动）** | `Qwerty Learner 官网 — 为键盘工作者设计的单词记忆与打字锻炼软件` | 保守演进 | 仅微调两字词，SEO 权重平稳过渡；不丢「官网」 | 未体现游戏模块 |
| **B（三合一宣言）** | `Qwerty Learner — 背单词 · 练打字 · 打字游戏，为键盘工作者而生` | 产品宣言 | 三能力一句讲清，口语化易记，差异化于同类背单词站 | 无「官网」二字；「打字游戏」为新关键词需积累 |
| **C（原句式扩展）** | `Qwerty Learner 官网 — 为键盘工作者设计的记忆与肌肉锻炼软件` | 保留原句式 | 「单词」→「记忆」覆盖中文打字；「肌肉记忆锻炼」精华保留 | 较抽象，新用户get不到「打字」 |
| **D（双模式并列）** | `Qwerty Learner / Typing Learner — 单词记忆 × 打字锻炼 × 打字游戏` | 架构直译 | 与产品内「学习模式/打字模式」双命名体系一致，老用户认组织 | 偏极客向；slash 标题在部分平台展示一般 |
| **E（训练场隐喻）** | `Qwerty Learner — 键盘工作者的英语与打字训练场` | 定位隐喻 | 「训练场」涵盖练习+游戏；短口传播 | 「训练场」与游戏的休闲感略有出入 |

> 推荐 **B**：三能力覆盖最全、与项目现状（打字模式 + 游戏中心已交付）匹配度最高；若重视官网 SEO 延续性则选 **A**。

> **✅ 2026-10-20 需求方选定候选 B**（确认项 2）。施工按 B 成套更新 `index.html`。

## 四、需同步的字段清单（选定候选后施工）

`index.html` 中以下字段**成套更新**，不允许只改 `<title>`：

| 字段 | 现值（摘要） | 动作 |
| --- | --- | --- |
| `<title>` | Qwerty Learner 官网 — 为键盘工作者设计的单词与肌肉记忆锻炼软件 | 替换为选定候选 |
| `meta[name=description]` | 「…免费英语学习软件，结合打字练习与单词记忆…」 | 改写：保留「免费/打字练习/单词记忆」，补「双拼、打字测速、打字游戏」 |
| `meta[name=keywords]` | 现有词库 + 考试类型关键词 | **追加**：双拼、小鹤双拼、打字测速、中文打字、打字游戏、墨雨、成语接龙、肌肉记忆；不清除既有词 |
| `meta[property=og:title]` | 同 title（旧文案） | 与选定 title 一致 |
| `meta[property=og:description]` | 旧 description | 同步改写 |
| `meta[property=twitter:title]` / `twitter:description` | 旧文案 | 同步 |
| 结构化数据 `WebApplication` | `name: Qwerty Learner`（产品名，**不改**）；`featureList` 罗列词库类能力 | **追加**：双拼练习、打字测速、打字游戏、中文打字、键位提示；`description` 同步 |

其他纪律：

- `<html lang="zh-Hans">` 等不变；canonical、OG image 路径不变。
- 文案用全角破折号「—」的既有风格（与现站一致），中英文之间空格规范与现站一致。
- 部署到 GitHub Pages 后抽查分享卡片（og 字段）与浏览器标签标题。
