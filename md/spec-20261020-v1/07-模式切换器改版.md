# 07 · 模式切换器改版

**日期**：2026-10-20
**负责成员**：析客
**文档性质**：需求定义，不含代码实现。
**对应需求**：批次需求 8 + 9（`00-README.md` §二 #8、#9）。

---

## 一、背景与目标

模式切换器（`src/components/ModeSwitcher/index.tsx`，`spec-20261017-v2/01` 的落地形态）当前形态：

- 标题块 = logo + 英文标题 + 右侧独立箭头按钮，整块作为 hover 热区；
- 浮层（白底卡片）**只显示未选中模式一项**，宽度与标题块（含 logo）一致，项内有一个 **64×64 隐形 logo 占位**（「前面空一块」的来源）；
- 展开时浮层第一帧渲染在标题块左上角（`top:0;left:0`，x/y 未就绪时为 0），随后才移动到计算位置 —— 观感是「**从左上角飞下来**」；
- 候选项 hover 出浅蓝背景（现样式可复用）。

需求提出方要求（本批次两连改）：

1. **删掉「从左上角飞下」的动效，只保留下拉特效**（需求 8）；
2. **布局改版**（需求 9）：图标排除在框范围外；框内同时列出「当前模式」与「可切换模式」；白底 + 浅蓝 hover 复用现候选样式，但**当前模式只做边框框选、无 hover 特效**；标题后的箭头改为**英文标题下方居中的圆角小长方形（内嵌倒三角）**；hover 整个标题触发起下拉。

**成功标准**：浮层第一帧即落在最终位置；面板与标题文字对齐且无占位空白；双项状态样式符合「当前=边框框选无 hover，候选=无边框 hover 浅蓝」；指示器新形态就位；持久化 / 确认条 / 键盘可达全部不回归。

## 二、功能需求

### REQ-701 消除「左上角飞入」，保留下拉特效

- 浮层**首次可见帧必须已在最终计算位置**：定位（floating-ui 的 x/y）就绪前，面板不得以可见状态出现在标题块左上角。实现约束（手段不限）：
  - 面板以不可见态（`opacity:0` + `aria-hidden`，或 `visibility:hidden`）挂载并完成测量，定位就绪后再触发可见过渡；或
  - 面板常驻 DOM 但 `hidden`，hover 时先就位再播过渡。
- **保留**的下拉特效：现 `<Transition>` 的 200ms 淡入 + 4px（`translate-y-1 → translate-y-0`）下落过渡，以及关闭时的 150ms 淡出。
- **保留** floating-ui `middleware: [offset(0), flip(), shift()]` 与「视觉 8px 间隙用 `translate-y` 实现」的方案（ENTRY2-05）及其透明 hover 桥。

### REQ-702 热区与面板对齐（图标排除在框范围外）

- **hover 热区维持「整个标题块」**（logo + 标题 + 指示器），即需求原文「hover 事件（整个标题的事件）」；进入 60ms 后展开、离开 150ms 后收起（参数不变）。
- **白框（下拉面板）与标题文字左缘对齐**：logo 区域排除在框范围外——面板不再横向覆盖 logo，宽度适配标题文字内容；**删除项内 64×64 隐形 logo 占位**（「前面空一块」修复）。
- 几何判定所需的 `data-mode-switcher-anchor`（热区）与 `data-mode-switcher-panel`（面板）标记保留（现行指针几何检测机制继续复用，ENTRY2-01/05）；浮层定位 reference 指向标题文字区（非 logo）。

### REQ-703 面板双项与状态样式

- 面板内**同时列出两项**：**当前模式**（不可切换，仅标识）与**可切换模式**（点击切换，逻辑含练习中确认条，MODE-06）。
- 面板样式：白底圆角卡片（复用现 `my-card bg-white dark:bg-gray-800`）。
- 每项结构：英文标题（大字）+ 中文模式名（`学习模式 / 打字模式`，英文下方小字）——与现候选项结构一致，**当前项也显示中文名**。
- **状态样式（本需求的核心区别）**：
  - **当前模式项**：仅**边框框选**（1px indigo 边框 / ring，圆角同项）；**无 hover 背景、无 hover 变色**（`cursor: default`，不可点击切换；点击仅收起浮层）。
  - **可切换模式项**：无边框；hover / focus-visible 时出**浅蓝背景**（`indigo-100` 系，深色 `indigo-800` 系）——**直接复用现候选模式样式**，不新造色。
- 高亮互斥不涉及（仅两个模式，恒为一当前一候选）。

### REQ-704 指示器改版

- **移除**标题右侧的独立箭头按钮（现 `h-8 w-8` chevron 钮）。
- **新增指示器**：位于**英文标题正下方、水平居中**（相对标题文字居中，非相对 logo）的**圆角小长方形**，长方形**中间内嵌一个倒三角**（▾ 语义）：
  - 尺寸量级：高约 14–18px、宽约 28–36px（与标题文字宽度协调，不抢视觉）；
  - 颜色 indigo 主色系（深色模式适配）；
  - 展开 / 收起状态：倒三角旋转 180°（保留现箭头的旋转反馈语义），或小长方形底色微加深，二选一以可辨认为准；
  - 点击行为：点击指示器 = 开 / 合浮层（继承现箭头按钮行为，含 `aria-haspopup` / `aria-expanded` / 键盘处理）。
- 点击标题文字 → 仍跳官网；浮层展开时点击标题先收起不跳转（ENTRY2-06 保留）。

## 三、交互 / UI 说明

新形态结构示意：

```
┌─────────────────────────────┐
│ [logo]  Qwerty Learner      │   ← hover 热区 = 整块（logo + 标题 + 指示器）
│         ▭▼▭                 │   ← 指示器：英文标题下方居中的圆角小长方（内嵌倒三角）
└─────────────────────────────┘
          ┌───────────────────┐
          │ Qwerty Learner    │ ← 当前模式项：indigo 边框框选，无 hover
          │ 学习模式          │
          ├───────────────────┤
          │ Typing Learner    │ ← 可切换模式项：无边框，hover 浅蓝背景
          │ 打字模式          │
          └───────────────────┘
        （面板与标题文字左缘对齐，不覆盖 logo；无隐形占位）
```

状态与边界：

| 状态 | 表现 |
| --- | --- |
| 默认 | 指示器倒三角朝下；无面板 |
| hover 标题块 60ms | 面板在最终位置淡入 + 4px 下落 |
| 鼠标移到面板 | 保持展开（hover 桥覆盖 8px 间隙） |
| 离开两者 150ms | 淡出收起 |
|  hover 候选项 | 浅蓝背景（indigo-100 / dark:indigo-800） |
| hover 当前项 | **无变化**（仅边框） |
| 点击当前项 | 仅收起浮层（不切换、不跳转） |
| 点击候选项 | 走现切换逻辑（练习中 → 确认条） |
| 键盘 | Tab → 指示器聚焦；Enter/Space/↓ 展开；↑/↓ 在两项间移动；Enter 选择；Esc 收起并焦点回指示器 |
| 深色模式 | 面板 `dark:bg-gray-800`；hover `dark:bg-indigo-800`；边框色深色适配 |

## 四、数据与接口

- 无新增持久化数据；`appModeAtom` / `pendingModeSwitchAtom` / `typingPracticeActiveAtom` 等既有 atom 不变。
- 组件内部：`useFloating` 的 reference 从「整块标题」调整为「标题文字区」（需新增一个 ref 节点承载定位 reference；热区 wrapper 保留为 hover 判定锚点）。
- DOM 标记 `data-mode-switcher-anchor` / `data-mode-switcher-panel` 保留（几何检测依赖）；指示器按钮建议加稳定 `data-testid`（如 `mode-switcher-indicator`）便于 E2E。
- 无障碍属性：指示器 `aria-haspopup="menu"` / `aria-expanded`；面板 `role="menu"`；两项 `role="menuitem"`，当前项加 `aria-current="true"` 且 `aria-disabled="true"`。

## 五、验收标准

1. hover 标题块：面板**第一帧即在最终位置**（无左上角闪现 / 飞入），200ms 淡入 + 4px 下落；离开 150ms 淡出。
2. 面板左缘与标题文字左缘对齐，宽度不含 logo 区域；项内无任何隐形占位空白。
3. 面板含两项：当前模式（indigo 边框、hover 无变化、不可切换）+ 可切换模式（无边框、hover 浅蓝、点击可切换）。
4. 标题右侧无独立箭头按钮；英文标题下方有居中圆角小长方形指示器，内嵌倒三角；展开时倒三角旋转反馈。
5. 点击指示器可开 / 合；点击标题文字跳官网（展开时先收起）；键盘全路径可用。
6. 持久化：切换模式后刷新 / 重开，仍落在上次模式（ENTRY2-09-1）。
7. 打字练习中切模式：确认条流程不变（MODE-06 / ACC-06-11）。
8. 回归：学习模式页头结构除 ModeSwitcher 外零变化（REG-15）；E2E（`scripts/probe-v2.cjs` 等既有探针）中模式切换相关用例全过。
