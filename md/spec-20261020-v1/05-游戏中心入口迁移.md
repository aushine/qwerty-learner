# 05 · 游戏中心入口迁移

**日期**：2026-10-20
**负责成员**：析客
**文档性质**：需求定义，不含代码实现。
**对应需求**：批次需求 6（`00-README.md` §二 #6）。

---

## 一、背景与目标

打字游戏模块（`spec-20261019-v1`，已归档 `(√)`）当前有两个入口，都在**素材选择页**上：

1. 中文 Tab 的二级选项行（`TypingSchemeSwitcher`）尾部「[游戏]」胶囊；
2. 英语 Tab 下方的「进入游戏中心」按钮。

需求提出方要求：把游戏中心入口**移到功能栏**，位置在「指法图示」与「设置」之间，**只显示一个手柄图标**（不要文字按钮）。

**动机**：入口从「选择素材的二级行」提升为「常驻功能栏操作」，与指法图示/设置同级；练习页（非选择页）也能一键进游戏中心。

**成功标准**：功能栏出现手柄图标入口；选择页两处旧入口移除；进入 / 返回 / 高亮链路完整；学习模式无游戏入口。

## 二、功能需求

### REQ-501 功能栏新增手柄图标入口

- 位置：`TypingSwitcher`（打字模式页头功能条）内，**「指法图示」（`HandPositionIllustration`）与「设置」（`Setting`）之间**，即现行顺序末两位变为 `… 深色模式 → 指法图示 → 【游戏中心】→ 设置`。
- 形态：**仅一个手柄图标**（复用 `~icons/tabler/device-gamepad-2`，该图标已被旧入口使用，无新增依赖）；图标尺寸/容器与相邻图标按钮一致（`h-7 w-7` 槽位、`Tooltip` 包裹）。
- Tooltip 文案：`游戏中心`。
- `aria-label="游戏中心"`，可键盘聚焦。
- 点击 → `navigate('/typing/game')`（游戏中心卡片页）。
- **激活态**：当前路由位于 `/typing/game` 或 `/typing/game/:gameId` 时，图标高亮（indigo 主色，与深色模式等按钮的激活态一致），便于识别「我在游戏里」。

### REQ-502 移除选择页旧入口

- 移除 `TypingSchemeSwitcher` 的「[游戏]」胶囊及其 `onSelectGame` prop（组件、Gallery 调用处、相关类型一并清理，不留死代码）。
- 移除 Gallery 英语 Tab 下的「进入游戏中心」按钮块（`Gallery/index.tsx` 中 `tab === 'en'` 分支）。
- 游戏中心页（`/typing/game`）与三个玩法内页（`/typing/game/:gameId`）**保持不变**：卡片、GameShell、GameHeader 的「返回」链路（玩法内页 → 游戏中心）继续可用。

### REQ-503 可见范围

- 仅**打字模式**功能栏显示（`TypingSwitcher` 本身只被 `TypingLearner` 使用，天然满足）。
- **学习模式**（`pages/Typing` 的 `Switcher`）不加游戏入口——游戏模块隶属打字模式（`spec-20261019-v1` 的产品决策不变）。

## 三、交互 / UI 说明

功能栏最终顺序（打字模式）：

```
[素材] [一命模式(02)] [Start/Pause] [音效] [循环] [汉字提示] [错题本] [统计] [深色] [指法图示] [🎮 游戏中心] [设置]
```

- 手柄图标常态灰色系（与相邻按钮一致），所在路由为游戏页时 indigo 高亮。
- hover 显示 `游戏中心` tooltip。
- 点击进入游戏中心；游戏中心页 GameHeader 的返回按钮回到 `/typing`（练习页），与迁移前一致。

## 四、数据与接口

- 无新增数据结构；无记录写入变化（游戏成绩仍走 `gameRecords` 表，`spec-20261019-v1` 不变）。
- 组件接口变更：`TypingSchemeSwitcher` 删除 `onSelectGame` prop；`TypingSwitcher` 内部新增导航按钮（用 `useNavigate`）。

## 五、验收标准

1. 打字模式任意页面（练习页 / 选择页），功能栏「指法图示」与「设置」之间出现手柄图标，hover 提示「游戏中心」。
2. 点击进入 `/typing/game`；从游戏中心返回 `/typing`；从玩法内页返回游戏中心——链路全部正常。
3. 位于游戏路由时手柄图标高亮；离开后恢复常态。
4. 选择页（中/英 Tab）不再有「[游戏]」胶囊与「进入游戏中心」按钮；`TypingSchemeSwitcher` 无残留 prop 与死代码（lint 通过）。
5. 学习模式页头无游戏入口，结构零变化。
6. 回归：游戏三玩法（墨雨/诗词射击/成语接龙）与成绩记录功能正常。
