## 一、背景与目标

打字模式语料（`src/resources/typingMaterials.ts` 注册表 + `src/corpus/` 源文件 + `scripts/build-typing-dicts.ts` 构建管线）当前规模：

| 类型 | 现状 | 备注 |
| --- | --- | --- |
| 字 | 全拼/小鹤各 500、3500 | 《通用规范汉字表》一级字表（PD） |
| 词 | 全拼/小鹤各 1000（CC-CEDICT BY-SA）+ 医学 367 + 计算机 408 | 医学/计算机为本项目自建 |
| 成语 | **仅注册小鹤 500** | `quanpin-chengyu-500.json` 已构建但未注册 |
| 短句 | **仅注册小鹤 200** | `quanpin-duanju-200.json` 已构建但未注册 |
| 文章（中） | 古诗文 12 / 轻松短文 10 / 白话短文 10（双方案） | 公版 |
| 英语 | 段落 25 / 文章 10 / 经典 6 | 原创 + 公版 |

需求提出方要求：① 字 / 词 / 文章数量扩充，来源从基线 spec 或免费公开资源中找；② 词 / 成语 / 短句 / 文章增加**专业分组**（医学类、计算机类）。

**成功标准**：扩充后各类型数量达标；新增「专业分组」维度并在选择页可见；所有新增语料**逐条过 A2 许可审查并建溯源档案**（无档案不得入库，A2 §2.1 末注 / §7.1）。

## 四、专业分组（需求 5）

### REQ-406 分组结构

- 选择页（`TypingLearner/Gallery`）新增一级分类 **「专业分组」**，与现有「中文·输入法练习」「文章练习」并列（第③级分组按 `category` 自动渲染，无需改分组组件，只需新卡片带新 `category`）。
- 「专业分组」内按**素材类型**（词 / 成语 / 短句 / 文章）× **专业**（医学 / 计算机）组织卡片，命名格式：`专业 + 类型 + 数量`（如「医学成语 300」）。
- 既有「医学常用词 / 计算机常用词」两张卡**迁入**「专业分组」分类（`category` 字段变更），与其他专业素材同组。
- 文章类专业卡 `chapterLabelMode: 'title'`（篇名显示，沿用 v2-03 成果）；难度徽标沿用（医学古文 = `adv`，短句 = `intro/mid` 按内容定）。

### REQ-408 数据管线

1. **corpus 源文件**（`src/corpus/zh/`）：新增 `zi-1000.txt`、`zi-3000-erji.txt`、`ci-3000.txt`、`chengyu-1000.txt`、`duanju-400.txt`、`chengyu-medical.txt`、`duanju-medical.txt`、`duanju-computer.txt`、`wenzhang-yixue.txt`、`wenzhang-computer.txt`；扩充既有 `ci-medical.txt`、`ci-computer.txt`、`wenzhang-*.txt`；英文扩充 `en/para.txt`、`en/essay.txt`、`en/classic.txt`。
2. **构建脚本**（`scripts/build-typing-dicts.ts`）：新增对应 `MaterialKind`（沿用现有 medical/computer 先例），产出 `public/dicts/` 下双方案 JSON。
3. **注册表**（`src/resources/typingMaterials.ts`）：新增/变更卡片（id 命名沿用 `zh-{scheme}-{kind}-{n}` 与 `en-article-*` 既有模式），维护 `length / chapterSize / chapterCount / difficulty / source / license`。
4. **署名与声明**：CC BY-SA 4.0 来源（CC-CEDICT、中文维基条目）须在选择页底部说明与仓库 `CREDITS`/`NOTICE`（如无则随本批次建立）中署名并注明我方修改（GAL-11-1 底部说明位已存在，扩展即可）。
5. **溯源档案**：按 A2 §7.1 A-1 逐篇/逐条建档案（建议放 `docs/corpus-provenance/`，每篇一个 md 或一个 CSV 索引 + 详情文件）。

## 六、验收标准

1. 选择页出现「专业分组」分类，内含 REQ-407 全部卡片；医学/计算机词卡已迁入该分类。
2. 全拼与小鹤下均可见：字 500/1000/3500/次常用3000、词 1000/3000/医学600/计算机600、成语 500/1000/医学300、短句 200/400/医学200/计算机200、文章三类中文 + 医学古文选 + 计算机入门文章。
3. 每张卡可正常加载、分章、练习；文章类显示篇名；难度徽标正确。
4. 全部新增语料有溯源档案；CC BY-SA 来源在选择页底部与 CREDITS/NOTICE 署名。
5. 回归：既有卡片 id / 记录（`dict` 字段 = 素材 id）不受迁移影响——注意「医学/计算机词卡」仅 `category` 变更，**id 不变**，历史章节记录继续可查。
6. 构建产物体积增量在可接受范围（施工时报告增量 MB）。
