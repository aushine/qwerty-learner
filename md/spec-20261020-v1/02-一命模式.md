# 02 · 一命模式

**日期**：2026-10-20
**负责成员**：析客
**文档性质**：需求定义，不含代码实现。
**对应需求**：批次需求 2（`00-README.md` §二 #2）。

---

## 一、背景与目标

需求提出方要求在打字模式练习页提供一个**「一命模式」开关**：开启后，练习中**打错一次就从当前章节/文章的开头重新开始**（一条命，没有第二条）；关闭时维持现有行为（对码轨重打当前词、上屏轨标红继续）。

这是一个**用户级错误处理策略开关**，与基线 `spec/02` §4（CN-J2）的三档 `errorHandlingStrategy` 正交：一命开启时，覆盖既有策略，升级为「整章重开」。

**成功标准**：开关位置、默认值、两轨行为、持久化、边界情况全部确定且可验收；关闭时与现状逐字节一致（零回归）。

## 二、功能需求

### REQ-201 开关位置与形态

- 位置：打字模式页头功能栏（`Header` 的 `nav` 内），**`StartButton`（start/pause）左侧**，即现行顺序 `TypingMaterialButton → StartButton → TypingSwitcher` 变为 `TypingMaterialButton → 一命模式开关 → StartButton → TypingSwitcher`。
- 形态：一个**开关（toggle switch）**，带文字标签「一命模式」；hover 有 tooltip 说明「打错后从本章开头重新开始」。
- 样式：容器复用功能栏现有图标按钮的视觉语言（`my-card` / 与相邻按钮同高），开关本体用现成的 toggle 样式（或 `@radix-ui/react-switch` 若已在依赖中；不得新增大依赖）。
- **仅打字模式显示**；学习模式（`pages/Typing`）页头不加此开关（REG-15：学习模式页面结构不改）。

### REQ-202 语义

| 开关状态 | 对码轨（全拼/双拼） | 上屏轨（打字测速 / 英语） |
| --- | --- | --- |
| **开（一命）** | 输错任意一个字母 → **立即整章重开** | 上屏提交中出现错字 → **立即整章重开** |
| **关（默认按素材，见 REQ-203）** | 维持现状：打错字母 → 当前词重新输入（`rollbackWord`） | 维持现状：错字标红、游标继续（`markOnly`） |

「整章重开」的精确动作（REQ-205）：章节从头开始，**计时归零、统计归零、进度归零**，不出结算、不写成绩记录。

### REQ-203 默认值规则（按素材类型）

| 素材类型（`materialType`） | 默认 |
| --- | --- |
| `zi`（字）/ `ci`（词）/ `chengyu`（成语）/ `duanju`（短句）/ `paragraph`（英语段落） | **开** |
| `wenzhang`（文章）/ `article`（文章）/ `classic`（经典） | **关** |

- 即需求原文「只有文章训练默认关闭，字、词、成语或者其他模式默认开启」。
- 英语 `paragraph`（English Paragraphs，80–150 词短段落）按「非文章」默认开启（见 `00` §四待确认项 3）。
- **用户手动切换过 → 持久化覆盖默认值**：见 REQ-206。

### REQ-204 判定时机与反馈

- **对码轨**：判定时机 = 现有错误判定点（按错字母、播放 beep、`REPORT_WRONG_WORD` 之后、300ms 处置窗口之前）；一命开启时不再进入「重打当前词」，直接整章重开。
- **上屏轨**：判定时机 = `compositionend` / input 兜底路径的**提交判定点**（`01` REQ-104：提交即既成事实，退格不能撤销）。
- 重开时给一次**非阻塞提示**（复用页面层 `notice` toast 机制，SPEED2-11 同款）：「一命模式：打错重来」，4 秒自动消失；不弹窗、不阻断。
- 重开过程**不停顿**：`isTyping` 保持 `true`，用户可直接继续从题首开始打（不要求重新按开始键）。

### REQ-205 整章重开的动作定义

对码轨与上屏轨统一为「章节重置 + 立即继续」：

1. 章节数据重置：`chapterData` 的 `index = 0`、`correctCount / wrongCount / wordCount = 0`、`userInputLogs` 重建（等价 `REPEAT_CHAPTER` 的动作集合，`shouldShuffle` 按当前 `randomConfig`）；
2. 计时器归零（`timerData.time = 0` 及派生 accuracy/wpm 归零）；
3. `isTyping = true`（保持练习态）；
4. **上屏轨附加**：`UpstreamPanel` 的 `states / cursor / composing / finishedRef` 全部复位（实现上建议由页面层传入一个 `restartNonce` 作为 `key` 重挂载，或等价机制——因为上屏轨面板状态是组件内部 state，`REPEAT_CHAPTER` 不会触达）；
5. **不**触发 `FINISH_CHAPTER`、**不**写章节记录、**不**弹结算页；
6. 不消耗「同一题循环次数」（`LoopWordSwitcher`）计数——一命重开是错误处置，不是主动重开。

### REQ-206 持久化

- 新增持久化 atom：`typingOneLifeOverrideAtom = persistedAtom<boolean | null>('typingOneLifeOverride', null)`：
  - `null` = 用户未表达过偏好 → **按当前素材类型取默认值**（REQ-203 表）；
  - `true / false` = 用户手动切换过的值 → 跨会话、跨素材保持。
- UI 开关反映的是**生效值**（`override ?? defaultByMaterialType`）；用户每次切换都写入显式 `true/false`。
- 默认值随素材切换**动态重算**（仅当 `override === null` 时可见地变化）。

### REQ-207 边界情况

| 边界 | 规则 |
| --- | --- |
| 练习中途切换开关 | 立即生效，**不追溯**：已发生的错误不补判；下一次错误按新状态处置 |
| 一命开启但当前素材是文章（用户手动开） | 按一命执行（文章打错也整章重开）；提示文案不变 |
| 一命重开时正好处于暂停（失焦 / 模式切换确认条） | 暂定：重开动作照常执行（状态归零），是否自动恢复 `isTyping` 按既有「确认条消失自动恢复」逻辑（ACC-06-11）走；实现时不得出现「归零了但计时器/输入双停」的死锁 |
| 一命 + 随机洗牌（`randomConfig.isOpen`） | 重开时按当前配置重新洗牌（与手动 Restart 一致） |
| 上屏轨一命重开 + 首键计时 | 重开后 `hasStartedKey` 复位，下一次按键重新开始计时 |
| 学习模式 | 无此开关、无此行为 |

## 三、交互 / UI 说明

- 功能栏槽位：`[素材按钮] [一命模式 ◯——] [Start/Pause] [音效/循环/汉字/错题本/统计/深色/指法/设置]`。
- 开关态视觉：开 = indigo 主色 + 滑块居右；关 = 灰色 + 滑块居左；两种态都可读当前状态（不只靠颜色，滑块位置即状态）。
- Tooltip 文案：`一命模式：打错后从本章开头重新开始`。
- 一命触发重开时的 toast：`一命模式：打错重来`（页面底部居中，复用 notice 样式）。

## 四、数据与接口

- 新增 store：`src/store/typingMode.ts` 中 `typingOneLifeOverrideAtom`（持久化 key `typingOneLifeOverride`）。
- 新增纯函数（建议放 `src/resources/typingMaterials.ts` 或就近 hook）：`defaultOneLife(materialType): boolean`，实现 REQ-203 表。
- 新增 reducer 动作或在页面层组合既有动作完成 REQ-205；**不新增**与 `REPEAT_CHAPTER` 语义重复的动作类型（优先复用，保持 store 收敛）。
- 上屏轨面板需要接收复位信号（`restartNonce` prop 或等价 key 机制）——接口变更点仅此一处。

## 五、验收标准

1. 打字模式页头，Start/Pause 左侧出现「一命模式」开关；学习模式页头无此开关。
2. 选「常用 500 字」（默认开）：打错一个字母 → 章节立即从头开始，计时/统计/进度归零，`isTyping` 保持，出现「一命模式：打错重来」提示一次，不弹结算、不写记录。
3. 选文章类素材（默认关）：打错 → 维持现状（对码轨重打当前词 / 上屏轨标红继续），不整章重开。
4. 手动把开关切到关 → 刷新页面 → 仍为关（持久化）；手动切到开 → 切到文章素材 → 仍为开（覆盖优先）；清掉持久化后选文章 → 恢复默认关。
5. 上屏轨（中文打字测速 / 英语段落）一命开启：上屏错字 → 立即整章重开；重开后退格、首键计时均正常。
6. 中途切换开关不追溯：开→关后已发生的错误不补判，下一错按关处置。
7. 一命重开不消耗循环次数计数；随机洗牌配置下重开按配置洗牌。
8. 回归：关闭一命时，对码轨 / 上屏轨全部现有行为与改版前一致。
