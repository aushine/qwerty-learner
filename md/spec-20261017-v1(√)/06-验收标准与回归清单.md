# 06 · 验收标准与回归清单

**日期**：2026-10-17
**批次**：`spec-20261017-v1`
**上游**：`本批次 01`~`05` 的验收条目汇总 + 学习模式零回归 + 视觉一致性审计

---

## 1. 背景与目标

本批次是**纯增量改造**，最大的验收风险不是「打字模式做不出来」，而是「**做出来了，但把学习模式弄坏了**」。因此验收分三块：

| 块 | 内容 | 权重 |
|---|---|---|
| **A. 打字模式功能验收** | 从入口到结算的完整闭环 | 必须全过 |
| **B. 学习模式零回归** | 380 词典、发音、释义、默写、错词本、统计、路由 | **一票否决** |
| **C. 视觉一致性审计** | 是否「自创样式」 | 必须全过 |

## 2. A. 打字模式功能验收（端到端）

### 2.1 主流程

| # | Given / When / Then |
|---|---|
| **ACC-06-01** | Given 我在 `/`（学习模式），When 鼠标移到标题下方箭头，Then 出现下拉，含「学习模式」「打字模式」 |
| **ACC-06-02** | When 点击「打字模式」，Then 进入 `/typing`，页头第一个按钮为「中文 · 全拼」 |
| **ACC-06-03** | When 点击该按钮，Then 进入 `/typing/gallery`，顶部仅 2 个 Tab（中文/英语） |
| **ACC-06-04** | When 选中「中文」并点击「双拼」→ hover 展开 → 选「小鹤双拼」，Then 卡片刷新为小鹤版 |
| **ACC-06-05** | When 点击「字」胶囊 → 点「常用 500 字」卡片，Then 回到 `/typing`，页头显示「中文 · 小鹤双拼」「第 1 章」 |
| **ACC-06-06** | When 按任意字母键开始，Then 计时启动、题面显示目标编码（如「中」→ `vs`）、汉字提示显示「中」、键盘上 `V` 键高亮 |
| **ACC-06-07** | When 依次敲 `V` `S`，Then 键盘 `V` 完成态、`S` 高亮、打完自动进入下一题 |
| **ACC-06-08** | When 敲错一个键，Then 本题变红 + 键盘抖动 300ms + 300ms 后清空重打 |
| **ACC-06-09** | When 打完 10 题（1 章），Then 结算页弹出，指标含「字/分」，点「下一章」进入第 2 章 |
| **ACC-06-10** | When 切到「英语」Tab 并选段落素材，Then 键盘仍显示（无标注），可正常英文打字，`Esc` 暂停 |
