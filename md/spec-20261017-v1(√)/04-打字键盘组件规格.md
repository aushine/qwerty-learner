**日期**：2026-10-17
**批次**：`spec-20261017-v1`
**对应需求**：用户需求 ⑦（练习内容下方添加一块键盘，键上显示对应按键提示，以「Q 左上角大字、中间 iu」为例）

## 1. 背景与目标

### 1.1 背景

打字模式的用户（尤其双拼新手）在练习时最大的认知负担是「**这个字该按哪两个键**」。学习模式用「发音」解决「这个词怎么读」，打字模式必须用「键盘」解决「这个字怎么打」。

现有项目已有 `HandPositionIllustration`（指法手图）与（基线规划的）`SchemeKeyboard`（方案键位图），**两者都不是本批次要的东西**：

| 现有/规划组件 | 回答的问题 | 为什么不能直接用 |
|---|---|---|
| `HandPositionIllustration` | 哪个手指按哪个键 | 双拼用户已知盲打，要学的是「韵母在哪」而不是「手指在哪」 |
| `SchemeKeyboard`（基线） | 26 个字母键各自承载什么声母/韵母 | 是**脱离键盘实体的字母方块阵列**，且只有 26 键；用户在真实键盘上敲键时**对不上位置**（尤其数字行、Tab、Shift 的位置关系） |
| **`TypingKeyboard`（本组件）** | **真实键盘上，每个键承载什么** | ✅ 完整 QWERTY 形态，位置与实物一致，边打边看不用移眼 |

### 1.2 目标

| # | 目标 |
|---|---|
| G1 | 练习时**常驻显示**在题面下方，不需要点击展开 |
| G2 | 形态是**完整 QWERTY**（含数字行、Tab/Caps/Shift、空格行），按键位置与实物一致 |
| G3 | 每个字母键显示 **3 层信息**：主字母（大字）+ 声母（左上角）+ 韵母（主字母下方） |
| G4 | **当前应按的键高亮**，敲对即灭，敲错即闪红 |
| G5 | 视觉完全使用现有 Tailwind 色板与圆角，与页头卡片同一家族 |
| G6 | 可折叠（腾出空间）、可纯键盘操作、有文本等价物（a11y） |

### 1.3 非目标（本批次不做）

- ❌ 热力图着色（基线 K7）
- ❌ 悬浮半透明模式（K11）
- ❌ 导出壁纸（K12）
- ❌ 方案差异高亮 / 探针字校准（K13 / K14）
- ❌ 中文输入法上屏轨的候选窗示意
- ❌ 学习模式的键位图（本组件只服务打字模式，**不改 `HandPositionIllustration`**）

## 2. 键面信息的「三区」布局（KB-01，**本组件的核心设计**）

### 2.1 用户的原始描述

> 「上面的 Q 在左上角，中间就是（q 下面是 iu）；再下 W 按钮，就是一个大 W 在左上角，中间是（w 下面是 ei）」

即：**一个矩形键位里，主字母 + 韵母构成「一个整体」，声母以角标形式存在。** 用户口语里的「左上角」指**主字母相对于韵母的位置关系**（字母在上、韵母在下，整体居中/偏左上）。

### 2.2 三区定义

```
┌──────────────────┐
│ zh            │  ← 区 ①：声母区（左上角，h-2.5，text-[10px]）
│      Q        │  ← 区 ②：主字母区（居中偏上，text-lg 480 字重）
│      iu       │  ← 区 ③：韵母区（主字母正下方，text-[11px]）
└──────────────────┘
```

| 区 | 位置（相对键） | 字号 | 颜色（浅色/深色） | 何时出现 |
|---|---|---|---|---|
| ① 声母 | `absolute left-1 top-0.5` | `10px`，`font-mono` | `text-gray-400` / `dark:text-gray-500` | **仅当该键承载特殊声母**（小鹤：`V=zh`、`I=ch`、`U=sh`） |
| ② 主字母 | `flex-1 flex items-center justify-center`（垂直居中，但整体随 ③ 一起上移 2px） | `text-lg font-medium font-mono` | `text-gray-600` / `dark:text-gray-200` | 恒显示 |
| ③ 韵母 | 紧贴主字母下方 `-mt-0.5` | `11px`，`font-mono` | `text-indigo-500` / `dark:text-indigo-300` | 该键承载韵母时显示 |

**KB-01（必须遵守）**：

1. **主字母永远是大字、居中**；韵母是**小字紧贴其下**；声母是**角标**。
2. **同一键既有声母又有韵母时（`V`/`I`/`U`）**，三者同时显示（声母右上角标、主字母居中、韵母在下）。例如 `V` 键显示 `zh`（角标）、`V`（大字）、`ui`（下方，`ü` 用 tooltip 补充）。
3. **两个韵母的键**（如 `S = ong/iong`、`K = ing/uai`）**同排显示，用 `/` 分隔**：`ong/iong`。**不得**只显示第一个。
4. **不得**把声母/韵母堆叠成两行三行——那会让键高超过 44px，整块键盘放不进 `h-screen`（见 `02` LAY-02）。

### 2.3 「q 下面是 iu」的实现示意（ASCII 精确版）

> ⚠️ 下面用 ASCII 表达**布局关系**，实际用 Tailwind + `absolute` 实现。

```
第 1 行（数字行，不标注）
┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐
│~ ││1 ││2 ││3 ││4 ││5 ││6 ││7 ││8 ││9 ││0 ││- ││= │
└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘
 第 2 行（字母 + 韵母）
┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
│Tab ││  Q ││  W ││  E ││  R ││  T ││  Y ││  U ││  I ││  O │…
│    ││  iu││  ei││  e ││ uan││ ue ││ un │sh  │ch  │ uo │
│    ││  Q ││  W ││  E ││  R ││  T ││  Y ││  U ││  I ││  O │
└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘
```

> 🔴 **上表中的韵母内容仅用于说明布局，禁止作为实现依据。** 实现时必须打开 `基线 A1` §2.2 的表格逐键抄录，并核对：
> - `R = uan`（`er` 为待核对 C-1，**暂不标注**）
> - `Y = un`（`ün` 为待核对 C-2，**可视情况以 `un/ün` 标注但必须在 tooltip 标注「待核对」**）
> - `K = ing/uai`、`L = iang/uang`、`S = ong/iong`、`X = ia/ua`（**双韵母键，必须都显示**）
> - `V = zh`（声母角标）+ `ui`（韵母）
> - `I = ch`（角标）+ `i`（韵母）——**注意 `i` 在主字母 `I` 下方重复出现，这是正确的**（第一键语义 vs 第二键语义，`基线 A1` §2.1 的关键设计点）
> - `U = sh`（角标）+ `u`（韵母）
> - `;` 键在小鹤下**为空**（`基线 A1` §2.2 已确认官方 alphabet 不含 `;`），**不标注**

**KB-02（V/I/U 的特殊处理，最容易做错）**：这三个键在**第一键位置是声母、第二键位置是韵母**。因此键面必须同时表达两种语义：

```
┌──────────┐
│ zh       │  ← 声母角标（text-[10px] text-gray-400）
│    V     │  ← 主字母（text-lg）
│    ui    │  ← 韵母（text-[11px] text-indigo-500）
└──────────┘
```

当**当前应按的键是 V 且处于第一键位置**时：**只高亮声母角标**（`02` 基线 K4 的口径）。
当**处于第二键位置**时：**只高亮韵母文字**。

## 3. 键位布局与尺寸（KB-03 ~ KB-06）

### 3.1 行结构（ANSI 104 键的 6 行，**实现简化版**）

| 行 | 键 | 键数 | 说明 |
|---|---|---|---|
| 0 | `` ` `` `1`…`0` `-` `=` `Backspace` | 13 | **不标注**声韵母；`Backspace` 宽 2u |
| 1 | `Tab` + `Q W E R T Y U I O P` + `[ ]` `\` | 13 | `Tab` 宽 1.5u；**标注 Q~P 与 `[ ] \`**（`[ ]` 不承载韵母，留空） |
| 2 | `Caps` + `A S D F G H J K L` + `;` `'` `Enter` | 12 | `Caps` 1.75u、`Enter` 2.25u；**标注 A~L 与 `;`**（`;` 小鹤下为空） |
| 3 | `Shift` + `Z X C V B N M` + `,` `.` `/` + `Shift` | 12 | 左右 `Shift` 各 2.25u；标注 Z~M |
| 4 | `Ctrl` `Alt`(Win) `Alt`(Cmd) `Space` ... | 5 | `Space` 6u；**不标注** |
| 5 | — | — | 不画方向键簇（避免占宽） |

**KB-03（只标注字母键与必要的符号键）**：声韵母标注**只出现在 `Q~P` / `A~L` / `Z~M` / `;` 共 27 个键**上。数字行、Tab、Caps、Shift、Ctrl、Space **一律不标注**（它们是功能键，留空更干净）。

**KB-04（单位宽度 u）**：

| 视口 | `u`（键宽） | 键高 | `gap` | 总宽 |
|---|---|---|---|---|
| ≥1280px | `44px` | `44px` | `6px` | `≈718px` |
| 1024–1280px | `40px` | `40px` | `5px` | `≈652px` |
| 768–1024px | `36px` | `36px` | `4px` | `≈586px` |

实现建议：用 CSS 变量 `--kb-u` 在容器上定义，键宽 `w-[calc(var(--kb-u)*1)]`，特殊键 `w-[calc(var(--kb-u)*2.25)]` 等。**不要**为每档写一套 hack 类名。

**KB-05（总宽硬约束）**：键盘容器 `w-fit mx-auto`，且 `max-w-[92vw]`。**不得**出现横向滚动条。

**KB-06（与题面的间距）**：`TypingTarget` 与 `TypingKeyboard` 之间 `mt-6`；键盘下方距 `Progress` `mb-2`。总高控制在 `02` §3.2 给的 200~220px 预算内（`5 行 × 44 + 4 × 6 = 244px` 会超标 → **实现时允许略微压缩到 `h-[40px]` 与 `gap-[5px]`，合计 220px**）。

> ⚠️ **KB-06 的取舍说明**：6 行（含数字行）在 44px 时确实偏高。**优先级：行数完整 > 键高**。若实测溢出，**先压键高到 38px**（`38×5 + 5×4 = 210px`），**不要删行**（删了数字行会破坏「与实物一致」的核心价值）。

## 4. 视觉规格（KB-07 ~ KB-11）

### 4.1 键面（普通态）

| 属性 | 类名 | 依据 |
|---|---|---|
| 键背景 | `bg-white dark:bg-gray-700` | 与卡片内元素一致 |
| 键文字 | 主字母 `text-gray-600 dark:text-gray-200` | `Letter.tsx` normal 态 |
| 键边框 | `border border-gray-200 dark:border-gray-600` | 现有 `dict tag` 未选中态的相近处理 |
| 键阴影 | `shadow-sm`（**不要 `shadow-md` 以上**） | 保持扁平 |
| 圆角 | `rounded-lg` | 全站按钮圆角 |
| 韵母文字 | `text-indigo-500 dark:text-indigo-300` | 主色系 |
| 声母角标 | `text-gray-400 dark:text-gray-500` | 次要文字色 |
| hover（非练习态） | `hover:bg-indigo-50 dark:hover:bg-gray-600` | 与胶囊按钮 hover 一致 |

**KB-07（键盘容器的整体容器）**：

```
<div className="my-card mx-auto w-fit rounded-xl bg-white px-4 py-3 dark:bg-gray-800">
```

> 与 Header 的右上功能条、`Speed` 卡片同用 `my-card + rounded-xl + bg-white/dark:bg-gray-800`，形成「同一家族卡片」的视觉。

### 4.2 键盘标题栏

```
┌───────────────────────────────────────────────┐
│  小鹤双拼 · 键位提示                    [折叠]  │  ← h-6，text-xs，text-gray-400
├───────────────────────────────────────────────┤
│  （键区）                                      │
└───────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 标题文案 | `{方案中文名} · 键位提示`；全拼时「全拼 · 键盘」；英语时「键盘」 |
| 右侧按钮 | 文字按钮「折叠 / 展开」，`text-xs text-gray-400 hover:text-indigo-500` |
| 高度 | `h-6 mb-2 flex items-center justify-between` |

**KB-08（折叠状态记忆）**：折叠状态存 `typingKeyboardCollapsedAtom`（`atomWithStorage('typingKeyboardCollapsed', false)`）。**折叠后**只保留标题栏（`h-6`），题面自动垂直居中（因容器变矮）。折叠按钮必须有 3px 的焦点环（`focus:outline-none focus-visible:ring-2`）。

### 4.3 当前键高亮（KB-09）

| 状态 | 键外观 | 非颜色标记（a11y 必需） |
|---|---|---|
| **待按（next）** | `bg-indigo-500 text-white`，声母/韵母文字变 `text-white/80`，`ring-2 ring-indigo-300 ring-offset-1` | **底部 2px 实心条** + `scale-[1.03]`（形状差异） |
| **已按对（done）** | `bg-indigo-100 dark:bg-indigo-900/40`，主字母 `text-indigo-500` | 无（已完成不必强调） |
| **按错（wrong）** | `bg-red-50 dark:bg-red-900/30` + `border-red-400`，`animate-[shake_0.3s]` | **抖动动画**（非颜色）；`aria-live` 播报 |
| **闪烁提示（hint）** | `animate-pulse` 两次（800ms）后回到普通态 | 动画本身即非颜色标记 |

> 🔴 **KB-09-1**：**「待按」用 `indigo-500` 实心**，因为它是引导，不是评价。**不得用红色表示「该按这里」**（UI-HC-3 的精神：红色不得用于引导或负面评价）。
>
> 🔴 **KB-09-2**：**「按错」用红色是允许的**——它表达的是**事实性错误**（击键与目标不符），与「速度下降」无关。但**必须同时有抖动动画**，满足「颜色不作唯一信息载体」。

### 4.4 双拼 vs 全拼 vs 英语的标注模式（KB-10 ~ KB-12）

| 模式 | 主字母 | 声母角标 | 韵母 | 说明 |
|---|---|---|---|---|
| **小鹤双拼** | ✅ | ✅（仅 V/I/U） | ✅ | 完整三区 |
| **全拼** | ✅ | ❌ | ❌ | **只显示主字母**。理由：全拼的键位就是字母本身，标注 26 个韵母无意义 |
| **英语** | ✅ | ❌ | ❌ | 同上；但**保留当前键高亮与按错反馈**（用户仍在练打字速度） |

**KB-10（全拼/英语下的键盘价值）**：虽然无标注，键盘仍承担两件事：① 显示**当前应按的键**（相当于视觉化的击键提示）② 错误抖动。因此**全拼与英语模式下也必须渲染键盘**（不得因为「没标注」就隐藏）。

**KB-11（英语素材的行位置）**：英语文章打字时，当前键在**整篇文章**中的位置可能与中文相同（都是字母），无需特殊处理。

### 4.5 错误的非颜色反馈（KB-12 汇总）

| 场景 | 反馈 |
|---|---|
| 按错键 | 该键抖动 300ms + 整题变红（`02` §5.1）+ 错误音（现有 `playBeepSound`） |
| 卡住 3 秒未按键 | **闪烁当前应按的键两下**（`animate-pulse`，800ms），**不显示答案文字**（继承基线 K5 的立意：闪键位不给答案，逼用户自己回忆） |
| 长时间无输入（60s） | 提示「按任意键继续」（现有暂停逻辑） |

> **KB-12-1**：闪烁提示**不额外记录指标**（本批次不统计「依赖提示率」，那属于基线 `05` 的范围）。

## 5. 交互（KB-13 ~ KB-17）

| 编号 | 交互 | 规格 |
|---|---|---|
| **KB-13** | **悬停某键** | `Tooltip`（现有组件）显示该键承载的**全部**声母/韵母（含被省略的 `ü`/`ün` 等），格式：`V 键：声母 zh / 韵母 ui、ü`。**只显示事实，不显示记忆口诀**（继承基线 K6 的合规约束：不内置流传口诀） |
| **KB-14** | **点击某键** | 🟡 **可选（Should）**：产生等价击键（用于移动端降级与「鼠标点按」场景）。若实现，必须与 `keydown` 走同一个 `updateInput` 入口。⚠️ **本批次若未通过 Spike S1（password 方案失效），此项升级为 Must** |
| **KB-15** | **折叠 / 展开** | 见 KB-08 |
| **KB-16** | **切章 / 换素材** | 高亮位置重置到第一题的第一次击键 |

**KB-17（不显示手指指示）**：键盘上**不标注「该用哪个手指」**。理由同 `基线 02` §6.1（U1 已会盲打）。若未来要做，另立批次。

## 6. 无障碍（KB-18）

| # | 要求 |
|---|---|
| **KB-18-1** | 整个键盘容器 `role="group"` + `aria-label="{方案名} 键盘，{N} 个键标注了韵母"` |
| **KB-18-2** | 每个被标注的键有 `aria-label`，如「Q 键，韵母 iu」「V 键，声母 zh，韵母 ui」；**未被标注的键 `aria-hidden="true"`**（避免屏幕阅读器逐个播报 100+ 个键） |
| **KB-18-3** | 当前应按的键通过 `aria-live="polite"` 播报「请按 Q 键」。**仅在键变化时播报**（防刷屏） |
| **KB-18-4** | 键盘可 `Tab` 遍历（仅标注过的键），`Enter` 触发 KB-14 |
| **KB-18-5** | 颜色对比：`indigo-500` 底 + `white` 字对比度 ≥ 4.5:1（实测通过）；`text-[10px]` 的声母角标在深色模式下 **必须** `dark:text-gray-400` 以上亮度 |

## 7. 与基线 `SchemeKeyboard`（K1~K14）的取舍对照

| 基线项 | 内容 | 本批次 | 理由 |
|---|---|---|---|
| **K1** | 常驻显示 | ✅ **采纳** | 核心 |
| **K2** | 每键标注声母 + 韵母 | ✅ **采纳并强化**（改为「三区」+ 完整 QWERTY） | 用户需求 |
| **K3** | 声母/韵母分区配色 | 🟡 **部分采纳**：不同颜色（`gray-400` vs `indigo-500`），但**不做色块分区**（会破坏键的整洁） | 视觉更克制 |
| **K4** | 当前键高亮（第一键高亮声母区，第二键高亮韵母区） | ✅ **采纳** | `02` §5 |
| **K5** | 卡住闪烁（只闪键位不给答案） | ✅ **采纳**（KB-12） | — |
| **K6** | 悬停显示完整映射 | ✅ **采纳**（KB-13），**不含口诀** | 合规 |
| **K7** | 错误热力图着色 | ❌ **移出本批次** | 需要指标体系（基线 `05`） |
| **K8** | 可折叠 / 可遮盖 | 🟡 **只做折叠**（KB-08），不做「遮盖」 | 遮盖是「半毕业」概念，本批次无学习路径 |
| **K9** | 独立提示总开关 | ❌ **移出**（改为折叠 + 卡住闪烁不可关） | 简化 |
| **K10** | 可点击输入 | 🟡 **可选**（KB-14） | 视 Spike S1 结果 |
| **K11** | 悬浮半透明 | ❌ **移出** | 复杂度高、收益低 |
| **K12** | 导出壁纸 | ❌ **移出** | — |
| **K13** | 方案差异高亮 | ❌ **移出** | 只有小鹤一套可用 |
| **K14** | 输入法一致性校准 | ❌ **移出** | 属于 onboarding，本批次不做 |
| **新增** | 完整 QWERTY 形态（数字行/功能键/Space） | ✅ **本批次新增** | 与实物一致，是「边打边看」的前提 |
| **新增** | 折叠状态持久化 | ✅ **新增** | 体验 |

> **结论**：本组件 = 基线 `SchemeKeyboard` 的「K1/K2/K4/K5/K6/K8(折叠)」+ **完整 QWERTY 形态**。**两者共存不冲突**：`SchemeKeyboard` 用于「学方案」（后续批次），`TypingKeyboard` 用于「边打边看」（本批次）。

## 9. 数据结构（本组件的输入）

```ts
// 组件 props（只读，不在这里计算编码）
type TypingKeyboardProps = {
  scheme: 'quanpin' | 'flypy' | 'en'
  /** 当前题的目标编码（如 'vs'）；已完成前缀用 doneCount 表达 */
  targetCode: string
  /** 已正确击键数（= 当前应按的下标） */
  cursor: number
  /** 最近一次按错的物理键 code（如 'KeyX'），用于抖动；300ms 后置 undefined */
  wrongKeyCode?: string
  collapsed: boolean
  onToggleCollapsed: () => void
  onKeyClick?: (code: string) => void   // KB-14 可选
}
```

**KB-19（编码 → 物理键的映射）**：`targetCode` 是 `a~z` 的小写字符串；显示高亮时需映射到物理键（`'q' → 'KeyQ'`）。**映射必须是一张显式的 `Record<string, string>` 表**，不得用字符串拼接（`'Key' + ch.toUpperCase()` 对 `;` 等键失效）。

**KB-20（性能）**：键盘为**完全静态的 DOM**（约 90 个节点），高亮只改 className。**不得**在键盘上做每击键的 `setState` 全量重渲染——用 `useMemo` 缓存键位布局，仅 `cursor`/`wrongKeyCode` 变化时更新两个键。

## 10. 验收标准

| # | Given / When / Then |
|---|---|
| **ACC-04-01** | Given 进入小鹤双拼的单字练习，Then 题面下方**常驻**一块完整 QWERTY 键盘（含数字行、Tab、Caps、Shift、Space） |
| **ACC-04-02** | When 观察 `Q` 键，Then 主字母 `Q` 为大字居中，**正下方**显示 `iu`；`W` 键正下方显示 `ei` |
| **ACC-04-03** | When 观察 `V` 键，Then 同时显示 `zh`（左上角标）、`V`（大字）、`ui`（下方） |
| **ACC-04-04** | When 观察 `S` / `K` / `L` / `X`，Then 分别显示 `ong/iong`、`ing/uai`、`iang/uang`、`ia/ua`（**双韵母都显示**） |
| **ACC-04-05** | When 观察 `;` 键（小鹤），Then **无韵母标注**（空格） |
| **ACC-04-06** | When 切到全拼，Then 键盘仍显示，但**无声母/韵母标注**，仅主字母 |
| **ACC-04-07** | When 切到英语，Then 同 ACC-04-06 |
| **ACC-04-08** | Given 当前题目标为 `vs` 且未开始输入，Then `V` 键高亮（indigo 实心 + 底部条 + 微放大） |
| **ACC-04-09** | When 敲对 `V`，Then `V` 变为「已完成」浅色，`S` 变为「待按」高亮 |
| **ACC-04-10** | When 敲错键，Then 该键**抖动 300ms 并变红**（同时存在动画，不只靠颜色） |
| **ACC-04-11** | Given 3 秒未按键，Then 当前应按的键闪烁两下后恢复，**不显示答案文字** |
| **ACC-04-12** | When 点「折叠」，Then 键盘收起只剩标题栏，刷新后仍为折叠状态 |
| **ACC-04-13** | When 悬停 `K` 键，Then tooltip 显示「K 键：韵母 ing、uai」 |
| **ACC-04-14** | When 用 1280 / 1024 / 900 三档宽度查看，Then 键盘等比缩放，**无横向滚动条**，不超出 `92vw` |
| **ACC-04-15** | When 页面在 1366×768 下打开，Then 整页仍不滚动（键盘+题面+指标条全部可见） |
| **ACC-04-16** | When 开启深色模式，Then 键背景 `gray-700`、主字母 `gray-200`、韵母 `indigo-300`，对比度可读 |
| **ACC-04-17** | When 用屏幕阅读器（NVDA）浏览，Then 只播报被标注的键，且当键变化时播报「请按 Q 键」 |

## 11. 与既有 Spec 的关系

- **部分采纳** 基线 `02` §6.2 的 K1/K2/K4/K5/K6/K8（见 §7 对照表），**其余 K7/K9/K11/K12/K13/K14 明确移出本批次**。
- **新增** 完整 QWERTY 形态与折叠持久化，基线未定义。
- **键位事实一律引用** `基线 A1` §2.2 / §2.1 / §3.1，**本文档不复制映射表**。
- **不采纳** `基线 A1` §2.2 待核对项（`er`/`ün`）作为正式标注：`er` 暂不标、`ün` 标但 tooltip 注「待核对」。
- **不改造** 现有 `HandPositionIllustration`（继承基线 `02` §6.1 的警告）。
