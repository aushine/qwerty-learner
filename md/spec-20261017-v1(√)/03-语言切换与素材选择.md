## 1. 背景与目标

### 1.1 现状（代码事实）

打字模式的上一级选择器是**学习模式的「词典切换」**：

```
[词典切换: CET-4 ▾]  [第 1 章 ▾]
     ↓ 点击「CET-4」→ /gallery
/gallery 页：
  [🇺🇸 英语] [🇯🇵 日语] [🇩🇪 德语] [🇰🇿 哈萨克语] [🇮🇩 印尼语] [Code]   ← LanguageTabSwitcher（RadioGroup 下划线 Tab）
  ├ 中国考试 → 标签 [大学英语][考研][专业英语] → 卡片 CET-4 / CET-6 / 考研…
  ├ 专业词汇 → …
  └ …
```

即：**语言 Tab → 分类分组 → 标签胶囊 → 词典卡片**，四级。

### 1.2 打字模式需要的层级

```
语言（中文 / 英语）
 ├─ 中文：输入方式（全拼 / 双拼 ▾ 小鹤）→ 素材类型（字 / 词 / 成语 / 短句 / 文章）→ 素材卡片
 └─ 英语：素材类型（段落 / 文章）→ 素材卡片
```

**结论：复用现有 `/gallery` 的「Tab → 分组 → 胶囊 → 卡片」四级视觉结构，只替换每一级的语义。** 这正是「沿用学习模式样式」的最直接实现——不新画 UI，只换数据。

### 1.3 目标

| # | 目标 |
|---|---|
| G1 | 打字模式页头显示「语言切换」而非「词典切换」，点击进入 `/typing/gallery` |
| G2 | `/typing/gallery` 顶部是 **2 个 Tab（中文/英语）**，样式与现有 `LanguageTabSwitcher` 完全一致 |
| G3 | 中文下，**「全拼 / 双拼」是第二级按钮行**；双拼**hover 展开**二级选择（当前仅「小鹤双拼」可选） |
| G4 | 中文下，**「字 / 词 / 成语 / 短句 / 文章」是第三级胶囊行**（样式同 `DictTagSwitcher`） |
| G5 | 每次选择都实时回写 atom + URL 参数，返回练习页立即生效 |
| G6 | 任何一级的变更都**清除章节 index**（避免「第 5 章」在新素材里不存在） |

| 从 → 到 | 行为 |
|---|---|
| 中文 → 英语 | `typingLanguageTab='en'`；素材回落到英语上一次选择的素材（若无则 `en-article-para`）；**输入方式选择区隐藏**（英语无方案概念）；**不清除** `typingSchemeAtom`（下次回中文仍记得） |

## 4. 第 ② 级：输入方式（全拼 / 双拼）（GAL）

> 这是本批次**唯一新增的「二级选择」交互**，也是用户需求 ⑥ 的核心。

### 4.1 视觉位置

在语言 Tab 下方，独占一行，**左对齐、与 Tab 左缘对齐**：

```
[🇨🇳 中文] [🇺🇸 英语]
─────────────────────────
  [全拼]  [双拼 ▾]
```

### 4.2 按钮规格

| 项 | 内容 |
|---|---|
| 容器 | `flex items-center space-x-2 pt-6`（与 Tab 的 `pb-6` 形成 24px 间距） |
| 按钮（一级） | **复用 `DictTagSwitcher` 的胶囊样式**：`whitespace-nowrap rounded-[3rem] px-4 py-2`；选中 `bg-indigo-400 text-white`；未选 `bg-white text-gray-600 dark:bg-gray-800 dark:text-gray-200`，hover `hover:bg-indigo-100 dark:hover:bg-gray-600` |
| 右侧箭头（仅「双拼」） | `IconChevronDown h-4 w-4 ml-1 transition-transform duration-200`，展开时旋转 180° |
| 选中态判定 | 「双拼」在 `scheme ∈ {flypy}` 时为选中（**父按钮整体高亮**） |

> **GAL-06（重要视觉细节）**：用户描述的「**双拼按钮 hover 展开可以选择双拼模式**」，因此「双拼」既是**按钮**（可点，直接选中当前二级方案）又是**触发区**（hover 展开二级列表）。两种行为并存：**点击 = 选中「上次用过的双拼方案」**（默认小鹤）；**hover = 展开选择**。

### 4.3 二级下拉（双拼方案列表）

```
                    ┌────────────────────────────┐
        [双拼 ▾] ───│ ✓ 小鹤双拼    flypy          │
                    │   微软双拼    微软双拼（敬请期待）│  ← 置灰不可点
                    │   自然码      自然码（敬请期待）  │
                    │   搜狗双拼    搜狗双拼（敬请期待）│
                    └────────────────────────────┘
```

| 项 | 内容 |
|---|---|
| 定位 | `@floating-ui/react`，`placement: 'bottom-start'`，`offset(6)`，`middleware: [offset, flip, shift]`，`whileElementsMounted: autoUpdate` |
| 触发 | `useHover`（`delay:{open:80, close:200}`，**与 `01` ENTRY-05 同参数**）+ `useClick`（触屏与键盘） |
| 容器 | `listbox-options` 类 + `z-30 w-56`（复用 `DictChapterButton` 的 Listbox.Options 视觉） |
| 选项 | 左侧 `IconCheck`（选中且可用时）+ 中文名 + 右侧英文 id（`text-xs text-gray-400`） |
| 不可用项 | `opacity-40 cursor-not-allowed`，右侧小字「敬请期待」，**点击无反应但给出 `title` 提示**「第一版暂只支持小鹤双拼」 |
| 键盘 | `↓/↑` 移动、`Enter` 选中、`Esc` 关闭 |

**GAL-07（方案清单，硬约束）**：

| 顺序 | 中文名 | `schemeId` | 本批次状态 | 依据 |
|---|---|---|---|---|
| 1 | **小鹤双拼** | `flypy` | ✅ **可选中、可实现** | 用户明确「现阶段只给小鹤双拼添加功能」；键位表见 `基线 A1` §2.2（置信度 A） |
| 2 | 微软双拼 | `mspy` | 🚫 置灰「敬请期待」 | 基线 D4 的内置 5 套之一，本批次不实现 |
| 3 | 自然码 | `zrm` | 🚫 置灰 | 同上 |
| 4 | 搜狗双拼 | `sogou` | 🚫 置灰 | 同上 |

> 🔴 **GAL-08**：**置灰项必须在列表中可见**（让用户知道「以后会有」），但**不得**以任何方式让其可被选中（包括 URL 参数注入）。若 `typingSchemeAtom` 被外部写入非法值，页面回落 `flypy`。
>
> ⚠️ **GAL-09**：`微软双拼` 的 `ing` 在 `;` 键（`基线 A1` §2.2），与 F 键区冲突且需要扩展字符集——这也是本批次**不实现**它的技术原因之一。**在置灰项的 `title` 中不要暴露此技术细节**，统一文案「敬请期待」。

### 4.4 「全拼」的行为

| 项 | 内容 |
|---|---|
| 点击 | `typingScheme = 'quanpin'` |
| 是否展开二级 | ❌ 不展开（无二级） |
| 编码来源 | 每字 = 该字全拼（不带声调），见 `基线 A1` §5 |
| 键盘标注 | 键盘**只显示主字母**，不显示声母/韵母（因为全拼不需要记韵母键），见 `04` KB-13 |

**GAL-11-1（底部版权说明）**：直接**复用** `Gallery-N/index.tsx` 底部那段「本项目的词典数据来自多个开源项目…」的说明块（`IconInfo` + `text-xs` 的相同类名）。中文素材上线后**必须在该说明后再补一句**：「中文练习素材来源：字表取自《通用规范汉字表》（官方文件）；词组部分参考 CC-CEDICT（CC BY-SA 4.0）；短句与部分术语为本项目自撰；古诗文为公有领域作品。」——这是 `基线 A2` 的署名义务（BY-SA 的变更声明义务）。

> **为什么分组标题不用「专业词汇」「中国考试」**：那套分类是**词汇难度/用途**维度；打字模式的维度是**文本长度与认知负荷**（1 字 → 2-4 字 → 4 字 → 10-30 字 → 300+ 字）。硬套旧分类会让「医学词」「CET-4」混在一起，丢失递进关系。

## 6. 第 ④ 级：素材卡片（MAT）

### 6.1 卡片视觉

**MAT-01**：复用 `src/pages/Gallery-N/DictionaryWithoutCover.tsx` 的结构与类名（白卡、`my-card`、hover 抬升、选中态 `ring-2 ring-indigo-500`、`dark:bg-gray-800`），**只替换内容**：

| 词条形状 | **2-4 个汉字**（「算法」「数据库」「分布式系统」） |
| 来源 | ① 通用 IT/医学教材中的**高频术语**（术语本身不构成作品，属事实性表达）② **不得**整表搬运任何商业词典/术语表 |
| 校验 | 每个词条必须有拼音（构建期人工或脚本标注），**多音字必须按词读音**（「内存」→ `nèi cún`，不是 `nèi cún`→ 注意「行」「重」「长」「调」等） |
| 数量门槛 | **每份 ≥300 条**，少于 300 条不作为独立素材上线（合并进「常用词」） |

**MAT-05（短句必须原创）**：`基线 A2` §2.1 L4 行明确「现当代作家作品均在版权期 → 句子级语料改用公版白话或我方自行撰写」。因此**短句素材 100% 我方原创**（中性、无版权、教学用），例如「今天的会议改到下午三点」「请把这份文档同步给项目组」。**不得**摘抄小说/公众号/新闻。

**MAT-06（文章只用公版）**：文言短篇（《陋室铭》《爱莲说》）与唐诗宋词属公有领域；近现代白话文章**仅选作者卒年 + 50 年已过的作品**（如朱自清 1948 年卒，1999 年后进入公版），且**须在素材 `source` 字段注明作者、篇名、公版依据**（沿用 `基线 A2` §3 的判定规则）。**译本一律不用**（译本另有著作权）。

### 6.3 素材卡片的排序与默认

| 项 | 规则 |
|---|---|
| 卡片默认顺序 | 字 → 词 → 成语 → 短句 → 文章（**认知负荷由低到高**，对应 `基线 04` CP-1 原则） |
| 默认选中 | 中文 Tab 且无记忆时 → `zh-quanpin-zi-500` |
| 「推荐」标记 | 首次进入（localStorage 无 `typingMaterialId`）时，第一张卡片右上角加 `tooltip`「建议从这里开始」，**不强制** |

**MAT-07（不得用「难度星级」）**：不显示 ★ 难度——因为「字」不一定比「词」简单（生僻字 vs 常用词），会误导。用**长度与文本类型**表达递进即可。

## 7. 素材与方案的匹配规则（**矩阵**）

| 素材类型 | 全拼可用 | 小鹤可用 | 说明 |
|---|---|---|---|
| 字 | ✅ | ✅ | 两份 JSON |
| 词 | ✅ | ✅ | 两份 JSON |
| 专业词（计算机/医学） | ✅ | ✅（仅医学在本批次） | 各两份或回落 |
| 成语 | ✅ | ✅ | 本批次只交付小鹤版；全拼下**自动生成**并展示（编码生成成本极低，见 `05` DATA-04） |
| 短句 | ✅ | ✅ | 同上 |
| 文章 | ✅ | ✅ | 同上 |

**GAL-12（回落与徽标）**：若某素材在某方案下**没有**对应词典文件，则该卡片：
1. **仍显示**（保证入口完整）；
2. 右上角显示 `text-xs text-gray-400` 的「**仅 {另一方案名}**」徽标；
3. 点击时**自动切到有该素材的方案**（并 toast 提示「已切换到全拼」）。

> 这样避免「切到小鹤后发现少了 3 张卡片」的困惑，也不会出现空分组。

## 8. 状态、持久化与回填（GAL/DATA）

| 项 | 规格 |
|---|---|
| atom | `typingLanguageTabAtom`（`'zh'\|'en'`）、`typingSchemeAtom`（`'quanpin'\|'flypy'`）、`typingMaterialIdAtom`（`string`） |
| URL 回填 | `/typing/gallery` **不强制**带 query；若带 `?tab=zh&scheme=flypy&material=zh-flypy-zi-500`，则以 URL 为准并回写 atom（便于分享/调试）。**非法值一律忽略** |
| 选择后跳转 | 卡片点击 → `navigate('/typing')` |
| 章节重置 | **每次更换素材或方案 → `currentChapter = 0`**（必须；否则「第 20 章」在新素材里可能不存在） |
| 学习模式隔离 | 打字模式**绝不写** `currentDictIdAtom` / `currentChapterAtom`（学习模式的 atoms） |

## 11. 验收标准

| # | Given / When / Then |
|---|---|
| **ACC-03-01** | Given 在 `/typing`，When 查看页头第一个按钮，Then 显示「中文 · 全拼」（或用户上次选择），`Tooltip` 为「语言切换」 |

| **ACC-03-03** | When 选中「中文」，Then 下方出现「全拼 / 双拼」按钮行，且「全拼」为选中态（胶囊 `bg-indigo-400 text-white`） |
| **ACC-03-04** | When 鼠标移到「双拼」上，Then **≤150ms** 展开二级列表，含「小鹤双拼（可选）」及 3 个置灰项 |
| **ACC-03-05** | When 点击置灰的「微软双拼」，Then **不发生选中**，出现「第一版暂只支持小鹤双拼」提示 |
| **ACC-03-06** | When 选择「小鹤双拼」，Then 卡片列表刷新为小鹤版素材（名称不变，元信息行显示「小鹤双拼」） |

| **ACC-03-08** | When 点击「成语」胶囊，Then 仅显示成语卡片（本批次 1 张：常用 500 成语） |
| **ACC-03-09** | When 点击任意卡片，Then 进入 `/typing`，页头显示该素材名，章节为**第 1 章** |

## 12. 与既有 Spec 的关系

- **取代** `基线 01` CN-I6「在 `/gallery` 新增中文分类」的入口方案（同 `00` §4.2 S-1）。
- **采纳** `基线 04` §12.1 的 `id` 命名规范：`zh-<schemeId>-<level|type>[-<variant>]`（本批次扩展了 `type` 的取值：`zi / ci / chengyu / duanju / wenzhang`）。
- **采纳** `基线 A1` §4 的「小鹤不使用分号键」结论（影响键盘与字符集，不影响本页）。
- **采纳** `基线 A2` §2.1 的许可矩阵（字表用《通用规范汉字表》、词用 CC-CEDICT 署名、短句原创、文章公版）。
- **不采纳** `基线 04` 的 `level`（L0'~L7）字段与 `codeComplexity`（本批次不引入渐进课表，见 `00` §4.2 S-5）。
