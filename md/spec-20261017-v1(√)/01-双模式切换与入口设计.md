## 1. 背景与目标

### 1.1 背景

当前站点只有一个「模式」——以「单词 + 释义 + 发音」为核心的**学习模式**。它占据 `/` 路由，页头固定为「左上 Logo + 标题，右上功能条」。要让用户在两个模式之间来回切换，需要一个**常驻、低成本、不打断当前页面**的入口。

### 1.2 目标

| # | 目标 | 怎样算成功 |
|---|---|---|
| G1 | 用户**不离开当前页面**就能看到「还有一个打字模式」 | 鼠标移到标题下方箭头，0.15s 内出现下拉，下拉内可见「Typing Learner / 打字模式」 |
| G2 | 切换是「**模式级**」而不是「设置项级」 | 切换后 URL 变为 `/typing`（或回到 `/`），刷新后仍停留在该模式 |
| G3 | 切换**不污染练习状态** | 打字中切换模式 → 先暂停并弹确认；确认后进入新模式的初始态，原模式进度按章保存 |
| G4 | 样式与现有交互**完全一致** | 展开/收起的动效参数与右上 `StartButton` 的 Restart 按钮一致（`@floating-ui/react` 的 `useHover` + `offset(5)`）|

### 1.3 非目标

- ❌ 不做「工作区/项目」多级概念（只有两个模式）
- ❌ 不做模式间的数据互导
- ❌ 不做快捷键切模式（第一版留 `Ctrl+Shift+M` 作为**可选**增强，见 `ENTRY-08`）

## 2. 模式定义（MODE）

### 2.1 模式枚举

```ts
// src/typings/index.ts（新增，不改既有类型）
export type AppMode = 'learn' | 'typing'
```

### 2.2 模式总表

| 维度 | 学习模式 `learn` | 打字模式 `typing` |
|---|---|---|
| **路由** | `/`（不变） | **`/typing`**（新增） |
| **进入页面组件** | `src/pages/Typing/index.tsx`（**不改文件名，不改行为**） | **`src/pages/TypingLearner/index.tsx`**（新增） |
| **选择页** | `/gallery`（`Gallery-N`，不变） | **`/typing/gallery`**（新增，复用 `LanguageTabSwitcher` 的视觉规范，见 `本批次 03`） |
| **顶级选择器语义** | 词典（CET-4 / 考研 / …） | **语言**（中文 / 英语）→ 方案 → 素材 |
| **核心辅助物** | 发音 + 释义 | **输入键盘** |
| **数据来源** | `src/resources/dictionary.ts`（380 条） | **`src/resources/typingMaterials.ts`**（新增，见 `05`） |
| **模式级 atom 前缀** | 无（保持原样） | 一律以 `typing` 开头（`typingLanguageTabAtom` / `typingSchemeAtom` / `typingMaterialIdAtom`） |

> 🔴 **硬约束 MODE-01**：**不得复用打字的 atom 去承载学习模式的状态**，反之亦然。两个模式的 atom 命名必须可一眼区分（学习模式侧**不新增**任何 atom）。

### 2.3 路由表

```tsx
// src/index.tsx（新增两行，其余不动）
<Route path="/" element={<TypingPage />} />
<Route path="/typing" element={<TypingLearnerPage />} />        {/* 新增 */}
<Route path="/typing/gallery" element={<TypingGalleryPage />} /> {/* 新增 */}
```

**MODE-02（路由与 basename）**：现有路由在 GitHub Pages 部署时 `basename` 为 `/qwerty-learner`（见 `基线 00` 项目概况）。新增路由必须使用**相对 path**（`typing`、`typing/gallery`，不带前导 `/` 亦可，取决于现有写法），**不得硬编码绝对域名或 `/qwerty-learner` 前缀**。

**MODE-03（刷新直达）**：直接访问 `/typing` 时，若用户从未选择过素材，则**默认落到**「中文 · 全拼 · 单字」的第一章，并可正常开始练习（不弹任何引导页）。这是本批次最简单可用的首次体验。

### 2.4 模式状态持久化

```ts
// src/store/typingMode.ts（新增）
export const appModeAtom = atomWithStorage<AppMode>('appMode', 'learn')
export const typingLanguageTabAtom = atomWithStorage<'zh' | 'en'>('typingLanguageTab', 'zh')
export const typingSchemeAtom = atomWithStorage<'quanpin' | 'flypy'>('typingScheme', 'quanpin')
export const typingMaterialIdAtom = atomWithStorage<string>('typingMaterialId', 'zh-quanpin-zi-500')
```

| 项 | 规则 |
|---|---|
| 存储介质 | `localStorage`（`atomWithStorage`，与现有 `currentDict` / `currentChapter` **同级**） |
| key 命名 | `appMode`、`typingLanguageTab`、`typingScheme`、`typingMaterialId`（**不得**与现有 key 冲突；已核对现网 key 无同名） |
| 缺省值 | `learn` / `zh` / `quanpin` / `zh-quanpin-zi-500` |
| 读取失败 | 捕获异常 → 回落缺省值，**不阻断渲染**（与现有 `atomWithStorage` 行为一致） |

> **MODE-04**：`appModeAtom` **只用于入口高亮与「记住上次模式」**，**不得**用它来做渲染分支判断当前页面（当前页面由**路由**决定）。理由：若用 atom 做分支，浏览器前进/后退会与 atom 不一致，出现「URL 是 `/typing` 但页面显示学习模式」的错位。
>
> **MODE-05（关键）**：`appModeAtom` 的写入时机 = **用户点击下拉项之后**（进入 `onClick` 回调的第一行），而不是路由变化时。这样「直接访问 URL」不会把用户上次的模式覆盖成页面所在的模式。**替代方案（推荐实现）**：在路由变化后用一个 `useEffect` 同步 `appMode = pathname.startsWith('/typing') ? 'typing' : 'learn'`，两者皆可，但**必须只用一种**，避免双写竞态。

### 2.5 切换模式时的练习状态处理

| 场景 | 期望行为 | 依据 |
|---|---|---|
| 打字模式**未开始**（`isTyping === false`） | 直接跳转，无提示 | 无数据损失 |
| 打字模式**正在打字**（`isTyping === true`） | 先 `SET_IS_TYPING false`（暂停）→ 弹**非阻塞确认条**：「正在练习中，切换后将暂停本章。是否切换？[切换] [继续练习]」→ 点「切换」才跳转 | 与 `基线 02` §11.3 的「禁止 `alert()`」一致；**不得用原生 `confirm`**（阻塞事件循环，是 Issue #744 的同类病因） |
| 学习模式侧同理 | 同上（学习模式的行为**本批次不改**——现有实现可直接跳走，因为切走后 `blur` 会自动暂停；**验收时只要求打字模式侧做确认**） | 学习模式零回归 |

**MODE-06（确认条样式）**：确认条使用现有 `tooltip` / `my-card` 视觉（白底、`rounded-lg`、`shadow-md`、`dark:bg-gray-800`），固定在页头下方居中，**不遮挡练习区**，5 秒无操作自动收起（视为「继续练习」）。

**MODE-07（进度保存）**：切换前若 `state.chapterData.words.length > 0` 且已有输入，按现有机制**不触发** `FINISH_CHAPTER`（未打完不算成绩），仅保留 `currentChapter` 与已写入的 `wordRecords`。**不得为了「保存进度」而人为 finish 章节**（会污染正确率统计）。

## 3. 入口位置与结构（ENTRY）

### 3.1 现有页头结构（代码事实）

```tsx
// src/components/Header/index.tsx
<header className="container z-20 mx-auto w-full px-10 py-6">
  <div className="flex w-full flex-col items-center justify-between space-y-3 lg:flex-row lg:space-y-0">
    <NavLink className="flex items-center text-2xl font-bold text-indigo-500 ..." to="https://qwerty.kaiyi.cool/">
      <img src={logo} className="mr-3 h-16 w-16" />
      <h1>Qwerty Learner</h1>     ← ★ 箭头挂在这一行的下方
    </NavLink>
    <nav className="my-card ... rounded-xl bg-white p-4 ...">{children}</nav>
  </div>
</header>
```

### 3.2 目标结构

```
┌───────────────────────────────────────────────┐
│  [logo]  Qwerty Learner ▾          [右上功能条] │   ← ▾ 与标题同一视觉行，位于文字正下方居中
│          ┌──────────────────────────┐          │
│          │ ● 学习模式  Qwerty Learner │          │   ← hover 展开的下拉
│          │ ○ 打字模式  Typing Learner │          │
│          └──────────────────────────┘          │
└───────────────────────────────────────────────┘
```

**ENTRY-01（位置）**：箭头**垂直方向位于标题文字的下方**（`mt-0.5` 级微距），**水平方向与标题文字块居中对齐**（与 `h1` 同宽居中），不得左贴 logo、不得右浮出容器。

**ENTRY-02（形状与尺寸）**：使用 `~icons/tabler/chevron-down`（项目已有同族图标使用先例：`DictChapterButton`/`PronunicationSwitcher` 均已引入 `tabler` 图标集）。尺寸 `h-4 w-4`（移动/小屏 `h-3.5 w-3.5`），颜色与标题同色系（`text-indigo-500`），`transition-transform duration-200`，展开时**旋转 180°**。

> ⚠️ 不得新引入图标库或自绘 SVG。`tabler` 图标集已在 `unplugin-icons` 中启用（现有代码 `import IconChevronDown from '~icons/tabler/chevron-down'`）。

**ENTRY-03（无需额外占位）**：箭头**不额外增加页头高度**。实现方式：标题外层改为 `relative` 容器，箭头绝对定位在 `h1` 下方，或标题与箭头放在同一个 `flex-col` 中且箭头 `h-4` 由现有 `py-6` 的内边距吸收。**验收：页头总高度与改造前差值 ≤ 4px**（防止整页布局下移）。

### 3.3 下拉面板结构

| 行 | 文案 | 副文案 | 状态 |
|---|---|---|---|
| 1 | **学习模式** | `Qwerty Learner` | 当前模式 → 左侧实心圆点 + 文字 `indigo-500` + 行背景 `bg-indigo-50`（`dark:bg-gray-700`） |
| 2 | **打字模式** | `Typing Learner` | 非当前 → 空心圆点 + 文字 `gray-600`（`dark:text-gray-200`） |

**ENTRY-04（面板样式 token，全部来自现有类）**：

| 属性 | 取值 | 与现网一致的依据 |
|---|---|---|
| 容器 | `my-card rounded-xl bg-white p-1 dark:bg-gray-800` | 与页头右上 `nav` 完全一致 |
| 宽度 | `w-56`（224px） | 容纳「学习模式 / Qwerty Learner」不换行 |
| 行高 | `px-3 py-2 rounded-lg` | 与 `listbox-options` 内部项一致 |
| hover 态 | `hover:bg-indigo-400 hover:text-white transition-colors duration-300` | **与 `DictChapterButton` 的「词典切换」按钮 hover 完全一致** |
| 出现动效 | `opacity-0 → opacity-100`，`duration-100 ease-in` | 与 `DictChapterButton` 的 `Transition leave="transition ease-in duration-100"` 一致 |
| 层级 | `z-30` | 高于 `header` 的 `z-20`，低于弹窗类 `z-50`（避免盖住结算页） |

**ENTRY-05（hover 交互，照抄 `StartButton` 范式）**：

```tsx
// 参考现有实现：src/pages/Typing/components/StartButton/index.tsx
const { refs, context } = useFloating({
  open: isOpen, onOpenChange: setIsOpen,
  whileElementsMounted: autoUpdate,          // ← 必须
  middleware: [offset(5), flip(), shift()],  // offset(5) 与 StartButton 同值
  placement: 'bottom-start',                 // 贴标题左缘
})
const hover = useHover(context, { move: false, delay: { open: 80, close: 200 } })
const click = useClick(context)              // 触屏/键盘回车也能打开
const { getReferenceProps, getFloatingProps } = useInteractions([hover, click])
```

| 参数 | 值 | 说明 |
|---|---|---|
| `delay.open` | **80ms** | 防止鼠标划过标题时误弹 |
| `delay.close` | **200ms** | 留出「从箭头移到面板」的移动时间；**鼠标进入面板时不得收起**（`useHover` 的 floating 元素自动纳入 hover 区域） |
| `offset` | **5** | 与 `StartButton` 的 Restart 浮层同值 |
| `placement` | `bottom-start` | 面板左缘与标题左缘对齐 |
| `middleware` | `offset` + `flip` + `shift` | 小屏时自动翻转向上/左移，防止溢出 |

**ENTRY-06（面板打开条件）**：鼠标进入**箭头热区**（箭头 + 标题整块链接区域，`padding` 外扩 4px 提高命中率）。⚠️ **标题本身是 `<NavLink to="https://qwerty.kaiyi.cool/">`**（跳官网），因此：

- 鼠标**移到箭头上**时才展开（不是移到整行标题）——避免「想点官网却弹出了下拉」；
- 箭头区域必须 `onClick={e => { e.preventDefault(); e.stopPropagation() }}`，**点击箭头只切换面板开合，不跳转官网**；
- 若必须保留「点击标题跳官网」，则**把箭头做成标题 `NavLink` 的兄弟节点而非子节点**（推荐），从结构上消除点击冲突。

**ENTRY-07（键盘可达性，A11Y）**：

| 键 | 行为 |
|---|---|
| `Tab` | 焦点进入箭头按钮（`aria-haspopup="menu"`、`aria-expanded`） |
| `Enter` / `Space` | 打开/关闭面板（`useClick` 已含） |
| `↓` / `↑` | 在两项间移动焦点 |
| `Enter` | 确认当前项 → 切换模式 |
| `Esc` | 关闭面板，焦点回到箭头 |

**ENTRY-08（可选快捷键）**：`Ctrl+Shift+M`（macOS `Cmd+Shift+M`）切换模式。**第一版可选（Should）**，若实现必须：`preventDefault`，且**仅在 `isTyping === false` 时生效**。

### 3.4 切换动作

```ts
const onSelect = (mode: AppMode) => {
  if (mode === currentMode) return            // 点当前项：只收起面板
  setAppMode(mode)
  navigate(mode === 'typing' ? '/typing' : '/')
}
```

**ENTRY-09**：点击「打字模式」→ `navigate('/typing')`；点击「学习模式」→ `navigate('/')`。**两者都不带 query / state**，由各自页面的 atom 决定落到哪本素材/哪个词典。

**ENTRY-10（跨页一致性）**：下拉入口是 `Header` 的一部分，而 `Header` 同时被学习模式（`Typing/index.tsx`）、Gallery、Analysis 等页面使用。**因此：**
- 下拉在**所有使用 `Header` 的页面**都应出现（含 `/gallery`、`/typing/gallery`），保持全局一致；
- 但**面板中「当前模式」的判断必须基于路由**（同 MODE-04），而不是仅基于 atom；
- `/mobile` 分支不使用 `Header`，**不受影响**。

## 4. 状态与边界（ENTRY / MODE 汇总）

| 编号 | 条目 | 判定 |
|---|---|---|
| **ENTRY-11** | 面板打开时滚动页面 | 面板随参考元素定位（`autoUpdate` 已处理）；**不得**因滚动而残留错位 |
| **ENTRY-12** | 面板打开时点击页面其他区域 | 关闭（`useDismiss`），且不触发被点元素的默认行为之外的副作用 |
| **ENTRY-13** | 小屏（宽度 < 768px） | 页头变为 `flex-col`，箭头仍在标题下方居中；面板宽度降为 `w-48`，`placement` 由 `flip` 自动处理 |
| **ENTRY-14** | 深色模式 | 面板 `dark:bg-gray-800`，当前项背景 `dark:bg-gray-700`，文案 `dark:text-gray-200`；**必须实际切一次深色模式验收** |
| **ENTRY-15** | 面板层级与结算页 | 结算页 `ResultScreen` 为模态层，**打开时下拉不应可点**（由 `z-index` 与 `pointer-events` 自然隔离；若冲突，面板 `z-30` < 模态 `z-50` 即可） |
| **MODE-08** | 直接输入 `/typing` 但素材 id 失效（例如未来删了某素材） | 回落 `zh-quanpin-zi-500` 第一章，**控制台 warn，不弹错** |
| **MODE-09** | 从 `/typing` 切回 `/` 时学习模式的 `currentDictId` | **保持用户上次的词典**，不重置（不得因为进过打字模式而让学习模式回到 CET-4） |
| **MODE-10** | 浏览器后退 | URL 与页面一致（路由驱动），下拉高亮与之一致 |

## 6. 验收标准

| # | Given / When / Then |
|---|---|
| **ACC-01-01** | Given 我在任意使用 `Header` 的页面，When 鼠标移到标题下方箭头，Then **≤150ms** 内出现下拉面板，包含「学习模式」「打字模式」两行 |
| **ACC-01-02** | When 鼠标从箭头**直接移入面板**，Then 面板**不收起**；离开面板 200ms 后收起 |
| **ACC-01-03** | When 我在学习模式（`/`）打开面板，Then「学习模式」行显示为选中态（实心点 + `bg-indigo-50`） |
| **ACC-01-04** | When 点击「打字模式」，Then URL 变为 `/typing`，页面为打字模式；刷新后仍在 `/typing` 且下拉中「打字模式」为选中态 |
| **ACC-01-05** | When 在打字模式点击「学习模式」，Then 回到 `/`，且 `currentDictId` 与进入打字模式前一致 |
| **ACC-01-06** | Given 打字模式正在输入，When 点击「学习模式」，Then 出现非阻塞确认条（**不是** `alert`/`confirm`），点「继续练习」后页面不跳转、计时器恢复 |
| **ACC-01-07** | When 用 `Tab` 聚焦箭头并 `Enter`，Then 面板打开，可用 `↓` 选到「打字模式」并 `Enter` 进入 |
| **ACC-01-08** | When 打开深色模式，Then 下拉面板与选中态文字**均清晰可读**（无深底深字） |
| **ACC-01-09** | When 改造前后对比页头高度，Then 差值 ≤ 4px，整页无跳动 |
| **ACC-01-10** | When 点击箭头（非标题文字），Then **不发生页面跳转**（不会跳到 `qwerty.kaiyi.cool`） |

## 7. 与既有 Spec 的关系

- **取代** `基线 01` CN-I6 的「在词典选择页新增中文分类」入口方案 → 改为独立模式 + 独立路由（详见 `00` §4.2 S-1）。
- **继承** `基线 02` §11.3「禁止 `alert()`」→ 本批次所有确认交互一律非阻塞。
- **继承** `基线 00` §4.1 UI-HC 三条硬约束（本批次无新增评价类文案）。
- **不涉及** 学习模式页面的任何改动。
