# 05 · 数据与素材扩充

**日期**：2026-10-17（第二批）
**批次**：`spec-20261017-v2`
**对应需求**：支撑用户需求 ②（打字测速）、③（文章标题 + 难度分组 + 扩充）
**上游**：第一批 `05`（数据模型与构建管线）、基线 `A2` §3（公版判据）

---

## 1. 背景与目标

第一批的数据模型已经够用（`TypingWord { name, trans, notation, units, acceptedCodes }`），本批次只做**加法**：

| # | 目标 |
|---|---|
| G1 | 文章记录增加 `title` / `author` / `difficulty`，供课题面与章节导航使用 |
| G2 | 引入 `inputTrack`（`code` / `ime`），**不写在素材上**（它是用户选择，不是素材属性） |
| G3 | 文章素材从 22 篇扩到 **≥30 篇中文 + ≥20 篇英文**，并按难度分档 |
| G4 | 构建脚本支持在 `### 篇名` 后写难度标记，自动写入 `difficulty` |
| G5 | 所有新增文章**逐篇留公版依据** |

## 2. 数据结构（DATA2）

### 2.1 `TypingWord` 扩展（DATA2-01）

```ts
export type TypingWordDifficulty = 'intro' | 'mid' | 'adv'

export type TypingWord = {
  name: string
  trans: string[]
  usphone: string
  ukphone: string
  notation: string
  acceptedCodes?: string[]
  units?: TypingUnit[]
  // 🆕 本批次新增（仅文章类有）
  title?: string        // 篇名
  author?: string       // 作者（古诗文可能有朝代，如「李白」/「苏轼」，只存人名）
  difficulty?: TypingWordDifficulty
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 文章类必填 | 与 `### 篇名` 完全一致 |
| `author` | 可选 | 与 `notation` 首行的作者部分一致；无名氏作品不写 |
| `difficulty` | 文章类必填 | `intro` / `mid` / `adv` |

**DATA2-01-1（`notation` 不改）**：篇名仍保留在 `notation` 首行（用户会把标题一起打）。**新增字段只是「元数据」，不改变待打文本。**

### 2.2 输入轨（DATA2-02）

```ts
// src/typings/typing.ts
export type TypingInputTrack = 'code' | 'ime'
```

- **属全局状态**（`typingInputTrackAtom`），**不写进 `TypingMaterialResource`**；
- 理由见 `02` SPEED2-12-2：同一素材要能在两种轨下练。

### 2.3 素材资源扩展（DATA2-03）

```ts
export type TypingMaterialResource = {
  // …第一批字段不变…
  /** 🆕 素材内容难度（仅文章类；其余素材缺省） */
  difficulty?: TypingWordDifficulty
  /** 🆕 本章节显示模式：'chapter' = 第 N 章；'title' = 显示篇名（文章类） */
  chapterLabelMode?: 'chapter' | 'title'
}
```

| 字段 | 取值 | 用途 |
|---|---|---|
| `difficulty` | `intro/mid/adv` | 卡片难度徽标 + 难度子胶囊分组 |
| `chapterLabelMode` | `'title'`（wenzhang/paragraph/article）/ `'chapter'`（其余） | 页头章节按钮显示篇名还是章号 |

## 3. 构建脚本改动（DATA2-04 ~ DATA2-06）

### 3.1 语料格式扩展

**DATA2-04（新增难度标记行）**：`### 篇名` 之后、作者行之前，可写一行难度标记：

```
### 春
朱自清
@intro
盼望着，盼望着，东风来了，春天的脚步近了。
…
```

| 规则 | 说明 |
|---|---|
| 标记格式 | `@intro` / `@mid` / `@adv`（行首 `@`，比 `###` 轻量，且不会与正文冲突） |
| 缺省 | **不写时按自动规则推断**（见 DATA2-05） |
| 顺序 | 标记行可在作者行前后任意位置，解析时先扫标记再扫作者 |

### 3.2 自动难度推断（DATA2-05，缺省时）

```
字数为 N（只算汉字）：
  N <= 350   → intro
  N <= 900   → mid
  N > 900    → adv
文言/诗词（shi 文件）→ 强制 adv
```

**DATA2-05-1**：自动推断只是**兜底**，正式交付的语料**必须显式写 `@xxx`**（避免以后调整阈值导致难度漂移）。

### 3.3 输出（DATA2-06）

```ts
// build-typing-dicts.ts 的 'wenzhang' 分支
return {
  ...makeEntry(display, code, accepted, units),
  title: piece.title,
  author: piece.author,
  difficulty: piece.difficulty ?? inferDifficulty(piece),
}
```

- 英文 `en-para` / `en-essay` 同样输出 `title`（段落无标题时用 `Paragraph 1` 这类占位）与 `difficulty`。

## 5. 不影响的部分（DATA2-07）

| 项 | 结论 |
|---|---|
| Dexie schema | ❌ 仍不迁移。`track`（code/ime）**仍不落库**，第二批继续接受「对码与上屏记录混在 `chapterRecords` 里」；`dict` 字段已能区分素材 |
| 构建产物体积 | 文章扩充后 `public/dicts/zh/*wenzhang*` 约增加 250KB，**按需加载**，首屏无影响 |
| `pinyin-pro` | 仍只在 devDependency |

**DATA2-07-1（上屏轨的「字/分」不落库）**：结算页展示的字/分是**运行时派生值**，不写进 `ChapterRecord`（该表现有 `wpm` 口径是「题/分」，第二批不改）。**因此统计页看不到打字测速的字/分**——这是已知且接受的局限（与第一批 DATA-16 一致，留给统一迁移）。

## 6. 验收标准

| # | Given / When / Then |
|---|---|
| **ACC2-05-01** | When 打开任一文章 JSON，Then 含 `title` / `author` / `difficulty` 三个字段，且 `title` 与 `notation` 首行一致 |
| **ACC2-05-02** | When 检查 `@intro` / `@mid` / `@adv` 标记，Then 所有中文文章都有明确难度（不依赖自动推断） |
| **ACC2-05-03** | When 统计中文文章总数，Then ≥ 30；英文 ≥ 28 |
| **ACC2-05-04** | When 对比注册表 `chapterCount` 与实际 JSON 条目数，Then **完全一致** |
| **ACC2-05-05** | When 检查新增文章，Then 每篇有 `source` 出处与公版依据（`卒年 + 50 年` 或「公有领域古典作品」） |
| **ACC2-05-06** | When 检查素材里是否有 1960 年代去世的作者，Then **不存在**（除非已满 50 年） |
| **ACC2-05-07** | When 运行 `yarn build:typing-dicts`，Then 幂等（连跑两次产物字节一致） |
| **ACC2-05-08** | When 检查构建后 bundle，Then 仍不含 `pinyin-pro` |
