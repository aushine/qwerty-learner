## 📌 TL;DR

第一批已交付「打字模式（对码轨）」。本批次做 **4 件互不耦合的事**：

1. **模式入口重做**：把「箭头下面挂一个白色卡片 + 单行两列」的浮层，改成**整块标题区 hover 高亮 + 标题文字随 hover 模式实时切换**（`Qwerty Learner` / `Typing Learner`），并把「学习模式/打字模式」作为**中文字样追加在英文标题之后、仅 hover 时出现**。模式记忆已在第一批落地（`appMode`），本批次只做「视觉 + 交互」修正。
2. **新增「打字测速」= 上屏轨（`ime`）**：这是基线 `02` §3 的**上屏实战轨**第一次落地——**不管用户用什么输入法，看的是最终上屏的字**。中文下与「全拼 / 双拼」并列成第三项；英语下「就是打字测速」（用户原话：英语下面的「文章打字」文案删掉）。
3. **文章标题化 + 难度分组**：长文章不再显示「第 1 段 / 第 2 段」，改为**显示篇名**（数据里已有 `### 篇名`，当前被拼进 `notation` 首行）；文章素材**扩充并按难度分组**（入门 / 进阶 / 挑战）。
4. **键盘键帽排版修复**：`K / L / S` 等双韵母键的韵母文字溢出键帽（`iang/uang` 共 9 字符），以及 `Backspace / Shift / Ctrl` 等功能键字号过大超出键面；`⊞`（Win 键）换成**微软四色方块图标**。

## 🎯 核心结论卡片

| 项 | 结论 |
|---|---|
| **改动性质** | 第 1、3、4 项为**改造**（改第一批已交付的组件）；第 2 项为**新增**（新输入轨 + 新页面分支）。**学习模式 `/` 仍零改动** |
| **新增输入轨** | `ime`（上屏轨）：普通 `<textarea>` + 只信 `compositionend.data`。**与对码轨物理分离**（基线 `02` §3.5 的 B1~B4 四个阻塞点全部落实） |
| **口径纪律** | 上屏轨与对码轨**指标分开定义、分开标注、分开存储**（沿用基线 D1）。本批次上屏轨的核心指标 = **字/分（CPM）+ 字准确率 + 回改次数**；**不显示 WPM** |
| **难度分组** | 文章主题按 `难度 ×` 三维（字数 / 文言程度 / 生僻字密度）**人工定级**为 入门 / 进阶 / 挑战，不引入自动评分 |
| **最大风险** | 🟠 ① 上屏轨的「标点/换行是否必须打」若口径不清会让用户误以为漏字 ② 中文输入法上屏的**全角标点与目标不一致**（`，` vs `,`）会大量误判 ③ 文章扩充涉及**版权**（只能用公版，见 §3.4） |
| **验收总口径** | 学习模式零回归；第一批打字模式（对码轨）功能零回归；新入口 hover 行为与需求逐条对齐；键盘 27 个键的韵母**全部不溢出**（含 `iang/uang`） |

| 基线结论 | 出处 | 用法 |

## 6. 术语表

| 术语 | 定义 |
|---|---|
| **打字测速（上屏轨 / `ime` 轨）** | 用**用户自己的输入法**打字，校验的是**最终上屏的汉字**。不关心用户敲了几个键、用的是全拼还是双拼 |
| **对码轨（`code-match`）** | 第一批的判定方式：绕过系统 IME，校验**击键序列**是否符合目标编码 |
| **markOnly** | 打错只标红、继续往下打，不回滚整句（基线 `02` §4.2 的口径，句/文章级默认） |
| **篇名** | 文章素材的标题（数据里 `### 篇名` 的首行），本批次起作为章节导航的显示名 |
| **难度档** | 文章的人工定级：入门 / 进阶 / 挑战 |
