# 03 · 语言 Tab 文案与文章标题化 / 难度分组

**日期**：2026-10-17（第二批）
**批次**：`spec-20261017-v2`
**对应需求**：用户需求 ②（删掉「拼音输入法 / 文章打字」文案）、③（文章不显示「第一段/第二段」，显示标题；文章多一些并按难度分组）
**上游**：第一批 `03`（语言切换与素材选择）、`05`（数据模型）

---

## 1. 背景与目标

### 1.1 现状

| 位置 | 现状 | 问题 |
|---|---|---|
| 语言 Tab（`TypingLanguageTabSwitcher`） | 「中文 / **拼音输入法**」「英语 / **文章打字**」两行 | 副文案是**对功能的一次解释**，但在二级已经能看清（全拼/双拼/打字测速）；重复且占用高度 |
| 页头章节按钮（`TypingMaterialButton`） | 「第 1 段 ▾」 | 文章是有**篇名**的（数据里 `### 春` + `朱自清`），显示「第 1 段」丢掉了最重要的识别信息 |
| 文章卡片 | 诗文 12 篇 + 白话 10 篇，两类各 1 张卡 | 数量偏少；且**没有难度区分**，新手点进《荷塘月色》（1300 字）容易被劝退 |

### 1.2 目标

| # | 目标 |
|---|---|
| G1 | 语言 Tab 只显示「中文 / 英语」，无副文案 |
| G2 | 文章类素材的章节导航**显示篇名**（`春 · 朱自清`），下拉里逐篇列篇名 |
| G3 | 文章素材**扩充到 ≥30 篇**，并按**难度（入门 / 进阶 / 挑战）**分组，卡片按难度升序排列 |
| G4 | 难度分组**不改变**素材卡片的横向胶囊结构（沿用「字/词/成语/短句/文章」），难度在**卡片内部以徽标**体现，或作为文章的**二级胶囊** |

## 2. 语言 Tab 文案（GAL2-01 ~ GAL2-03）

**GAL2-01（删除副文案）**：`TypingLanguageTabSwitcher` 的 `sub` 字段与渲染**全部删除**。

| 项 | 改前 | 改后 |
|---|---|---|
| 结构 | 两行（`text-lg` 主 + `text-xs` 副） | **一行**（`text-lg`） |
| 高度 | `pb-1` + 两行 ≈ 44px | `pb-1` + 一行 ≈ 32px → 上方 `h-20` 容器保持不变（多余空间由 `items-center` 吸收，**不额外留白**） |

**GAL2-02（不要顺手加图标）**：第一批 GAL-03 的降级方案是「两个 Tab 都不带图标」。本批次**维持**该方案（不加国旗），避免「改文案」变成「改视觉」。

**GAL2-03（Tab 点击面积不变）**：删掉副文案后，`RadioGroup.Option` 的可点区域可能变小。**必须**保留 `px-2 py-1`（垂直内边距从 `pb-1` 扩到 `py-1`），保证点击区高度 ≥ 36px。

## 3. 文章标题化（GAL2-04 ~ GAL2-08）

### 3.1 数据现状

文章 JSON 的一条记录（`public/dicts/zh/quanpin-wenzhang-10.json`）：

```jsonc
{
  "name": "chunzhuziqingpanwangzhe…",        // 全篇编码
  "notation": "春 朱自清\n盼望着，盼望着，…",   // ① 篇名 + 作者 + 正文（混在一起）
  "units": [ { "char": "春", "code": "chun" }, … ]
}
```

**问题**：篇名与正文拼在同一个 `notation` 字符串里，前端**无法可靠拆出标题**（虽然首行是标题，但要在运行时按 `\n` 切）。

**GAL2-04（新增 `title` / `author` 字段）**：

```jsonc
{
  "name": "chunzhuziqing…",
  "notation": "春 朱自清\n盼望着，…",
  "title": "春",                // 🆕 篇名
  "author": "朱自清",            // 🆕 作者（可缺省）
  "difficulty": "intro",        // 🆕 难度档：intro / mid / adv
  "units": […]
}
```

> **`notation` 不改**（仍含首行标题），避免影响第一批的题面渲染（标题作为第一行会被当成要打的字——**这其实是合理的**：用户连标题一起打，符合「练一篇文章」的心智）。
> 若后决定「标题不参与输入」，则需在 `units` 层面把首行标记为 `skippable`（见 `02` SPEED2-05-2 的同一机制）。**本批次选择「标题也一起打」**（改动最小，且标题通常很短）。

### 3.2 章节导航显示篇名（GAL2-05）

**改前**：

```
[第 1 段 ▾]
  ☑ 第 1 段
    第 2 段
    …
```

**改后**：

```
[春 · 朱自清 ▾]
  ☑ 1  春
    2  匆匆
    3  绿
    …
```

| 项 | 规格 |
|---|---|
| 触发按钮文案 | `{title}` +（有作者时）` · {author}`；超长时 `truncate` 到 10 个汉字 + `…` |
| Tooltip | `切换文章`（第一条为 `章节切换` 之外的新文案） |
| 下拉项 | `序号 + 篇名`；`w-56`（比现有 `w-32` 宽，容纳篇名）；`max-h-[60vh] overflow-y-auto` |
| 选中文案 | 与按钮一致（篇名 · 作者） |
| 非文章素材 | **保持现有**「第 N 章」行为不变 |

**GAL2-06（篇名从哪来）**：
1. 优先读 `title` 字段（GAL2-04 新增）；
2. 缺失时**兜底**从 `notation` 首个 `\n` 前的内容拆：`首行.split(' ')[0]` 作标题、其余作作者；
3. 两者都拿不到 → 回落「第 N 篇」。

**GAL2-07（当前章节索引与标题的对应）**：`typingChapterAtom` 是 index，素材 JSON 是数组，**顺序一一对应**。因此章节列表在数据加载完后才能显示篇名——**加载中**显示「加载中…」，**加载失败**回落「第 N 篇」（不得阻塞页面）。

> ⚠️ **GAL2-07-1（数据来源）**：页头的 `TypingMaterialButton` 目前**不加载词表**（只读 `material.chapterCount`）。显示篇名需要额外拿到当前素材的**全部篇名**。方案：
> - **推荐**：新增一个轻量 hook `useTypingChapterTitles(materialId)`，用 `useSWR` 拉同一个 JSON，**只取 `title`/`author`**（同一 URL 会被 SWR 缓存命中，**不会二次请求**——`TypingPanel` 里 `useWordList` 已经拉了同一个 URL）。
> - 禁止：把整篇正文塞进 atom 常驻内存。

### 3.3 卡片与结算页的标题（GAL2-08）

| 位置 | 规格 |
|---|---|
| 文章卡片 | 卡片标题仍为素材集合名（「古诗文短篇」「现代散文」），**不逐篇列表**（否则卡片爆炸） |
| 结算页 | 标题下方加一行 `《{title}》`；对码轨显示「字/分」，上屏轨显示「字/分」 |
| 词表抽屉（若保留） | 每行显示 `篇名`，不显示编码摘要 |

## 4. 难度分组（GAL2-09 ~ GAL2-12）

### 4.1 定级规则（人工，不自动评分）

**GAL2-09（三个正交维度，人工定级）**：

| 维度 | 入门 `intro` | 进阶 `mid` | 挑战 `adv` |
|---|---|---|---|
| **篇幅** | ≤ 350 字 | 350 – 900 字 | > 900 字 |
| **文体** | 白话散文 / 短诗 | 白话散文（抒情密度高） | 文言 / 长散文 / 议论文 |
| **用字** | 基本无生僻字 | 少量书面语 | 含较多文言虚词与生僻字 |

> 定级以**篇幅为主、文体为辅**，三个维度**取最高档**（例：一篇 400 字的文言文 → 挑战）。

**GAL2-10（分组的 UI 形态，二选一，本批次选定 A）**：

| 方案 | 形态 | 结论 |
|---|---|---|
| **A（采用）** | **文章胶囊内部再分三个子胶囊**：`[入门] [进阶] [挑战]`，放在「文章」胶囊下方一行小号胶囊 | ✅ 改动小、与现有 `DictTagSwitcher` 一致、不影响其他素材类型 |
| B | 拆成三张独立的卡片（「文章 · 入门」…） | ❌ 卡片数量膨胀，与「素材类型胶囊」语义重复 |

```
中文 · 输入法练习
[字] [词] [成语] [短句] [文章 ✓]
      [入门] [进阶] [挑战]        ← 仅当选中「文章」时出现，小一号胶囊
┌─────────┐ ┌─────────┐ ┌─────────┐
│ 现代散文 │ │ 古诗文   │ │ 论语选段 │
│ 30 篇 · 3 档 …                    │
└─────────┘ └─────────┘ └─────────┘
```

**GAL2-11（子胶囊样式）**：复用 `DictTagSwitcher` 的胶囊样式，但 `px-3 py-1 text-sm`（比主胶囊小一档），未选中为 `bg-white text-gray-500 border border-gray-200`，选中仍是 `bg-indigo-400 text-white`。**不得**新建样式体系。

**GAL2-12（难度徽标）**：卡片右上角，在现有「素材类型」徽标左侧增加难度徽标（仅文章类）：
- 入门：`bg-emerald-100 text-emerald-600`（`dark:bg-emerald-900/40 dark:text-emerald-300`）
- 进阶：`bg-amber-100 text-amber-600`
- 挑战：`bg-rose-100 text-rose-600`

> ⚠️ **GAL2-12-1（颜色纪律）**：难度徽标属于「客观档位标识」，不是对用户的评价，故可用暖色/红系（不违反 UI-HC-3——那条禁的是「用红色表达速度下降」）。

## 5. 素材卡片分组调整（GAL2-13）

| 项 | 现状 | 改后 |
|---|---|---|
| 中文 · 文章分组 | 诗文 12 / 白话 10 两张卡 | **3 张卡**：`现代散文`（进阶）/ `古诗文`（挑战）/ `轻松短文`（入门），共 ≥30 篇 |

| 英语 Tab | 段落 / 文章 | **同样按难度分组**（入门 / 进阶 / 挑战），各 ≥10 篇 |

## 6. 验收标准

| # | Given / When / Then |
|---|---|
| **ACC2-03-01** | When 打开 `/typing/gallery`，Then Tab 只有「中文」「英语」两行文字，**无任何副文案** |
| **ACC2-03-02** | Given 我选了 `现代散文` 的第 2 篇（《匆匆》），When 回到 `/typing`，Then 页头章节按钮显示「**匆匆 · 朱自清**」，不是「第 2 段」 |
| **ACC2-03-03** | When 点开章节按钮，Then 下拉逐项显示「1 春」「2 匆匆」…，且可滚动（篇数 ≥30 时 `max-h` 生效） |
| **ACC2-03-04** | When 切换章节，Then 按钮文案随之变成对应篇名 |
| **ACC2-03-05** | When 选择「文章」胶囊，Then 下方出现 `[入门] [进阶] [挑战]` 三个子胶囊 |
| **ACC2-03-06** | When 点「入门」，Then 只显示入门档文章卡片，且卡片右上角有绿色「入门」徽标 |
| **ACC2-03-07** | When 从「文章」切到「字」，Then 难度子胶囊**消失**（仅文章类显示） |
| **ACC2-03-08** | When 查看文章卡片数量，Then 中文文章 ≥ 3 张卡、总篇数 ≥ 30 |
| **ACC2-03-09** | When 网络慢/加载失败，Then 章节按钮回落「第 N 篇」，页面不阻塞 |
| **ACC2-03-10** | When 打开英语 Tab，Then 也有难度子胶囊，且英文文章按难度分档 |
