# 02 - 墨雨 · 落字成画

**日期**：2026-10-19
**负责成员**：析客
**文档性质**：本批次**招牌新玩法**（基线 `09` 完全没有）。参考 Ink Rain（墨雨 / iSeodang）的「文字如墨滴下落、在沾染纸面前打出、每打对一词化成一笔、完成整幅画得奖励」机制，结合中文打字练习做本土化。
**边界声明**：**不含代码实现**；落字/锁定/连击/生命等共享引擎见 `01` REQ-03；输入双轨见 `01` REQ-04；红线见 `01` REQ-05。

---

## 一、背景与目标

需求提出人点名参考「墨雨（Ink Rain）」这类打字游戏。Ink Rain 是已被验证十余年的「下落式 + 成画反馈」打字范式：韩文/中文词如墨滴落下，在它弄脏纸面前打出，每个词画一笔，完成一幅画得奖励；连续打对累积连击加倍得分，打错断连击；练习模式永不失敗，挑战模式 90 秒 + 有限纸数。

**本玩法目标**：把该范式移植为中文打字练习的招牌游戏——字/词从纸面上方落下，逐字打出后由 **Canvas/SVG 程序化生成水墨笔触**（零素材许可风险，契合 `A2` §2.3「美术须自绘」），整幅「画」完成后给奖励分，形成「打字→看见一幅水墨画生长」的正反馈，区别于 ZType 的太空射击观感。

**成功标准**：墨雨玩法可玩、可成画、有练习/挑战双模式；笔触为程序化生成；复用现有语料与双轨输入；遵守红线。

---

## 二、功能需求

### MOYU-01 墨滴下落与自动锁定
- 字/词（取自 字/词 层语料）从屏幕上方「纸面」区域落下；落速随难度曲线（语料级别升档）平缓加快，**不靠提速加压**（对齐 `09` §3.2/§3.4 难度轴原则）。
- 用户直接开始打字，匹配当前输入前缀的目标**自动锁定**（对齐 Ink Rain）；多个同前缀时锁定最接近底线（最危险）的一个。
- 锁定后屏幕高亮该目标的当前应打键（复用第二批 `TypingKeyboard` 键位高亮）。

### MOYU-02 逐字打出 → 程序化水墨笔触
- 对码轨：逐字符校验物理键位（`code-match`），每打对一个汉字的完整编码（全拼/双拼），该墨滴消除并触发一笔笔触生成。
- 上屏轨：用用户自己的输入法上屏汉字（`ime`），整字/整词上屏后消除并触发笔触（复用第二批上屏轨口径）。
- **一笔 = 一个被正确打出的目标**。笔触由算法依据目标在「画布坐标系」中的位置与笔顺随机性生成（见 §三 UI），**不引用任何外部图片**。

### MOYU-03 成画奖励
- 画面预置若干「画位」（如一幅水墨山水由 N 笔构成）；每打出 K 个目标积累一笔，集满一幅画的笔数 → 该画「完成」→ 奖励分 + 视觉收尾（如钤一枚程序化印章）。
- 画位数量与语料 tier 关联：入门=简笔（少笔），挑战=繁笔（多笔）；具体笔数在 `05` 数据层配置。
- 单局可成多幅画；成画进度持久显示在画布角落。

### MOYU-04 双模式
- **练习模式**：不计时、不消耗生命、永不失敗（对齐 Ink Rain Practice）；适合新手找键、纯练习。
- **挑战模式**：限时（建议 90 秒，对齐 Ink Rain）或有限「纸数」（如 5 张），命耗尽/时间到即结束→复盘（见 `01` REQ-03）。

### MOYU-05 连击与放弃
- 连续打对累积 Combo，分数按倍率放大（对齐 Ink Rain + `09` §3.2 节奏玩法连击）。
- 按 `Backspace` 或 `Esc` 可放弃当前锁定的墨滴（对齐 Ink Rain），放弃不扣分但断连击。
- 墨滴触碰底线 = 漏打 = 扣 1 命（挑战模式）或仅消失（练习模式），并断连击。

### MOYU-06 红线与合规
- 遵守 `01` REQ-05 全部红线；无经济/赛季/时长等级/付费墙/失败羞辱。
- 笔触与印章为**程序化生成**，无外部素材（对齐 `A2` §2.3 美术自绘红线）；画意仅作视觉反馈，**不构成任何第三方 IP 引用**。

### MOYU-07 双轨与语料
- 复用 `01` REQ-04：对码轨（默认）/ 上屏轨切换；语料复用 `typingMaterials` 的 字/词 层（详见 `05`），英语 Tab 可复用英文字词。

## 三、交互 / UI 说明

- **布局**：上半部为「纸面 + 落字区」（墨滴从中落下）；中央/背景为逐渐生长的水墨画布（程序化笔触叠加）；底部状态条（分数/连击/生命或剩余时间/纸数）+ 复用 `TypingKeyboard`。
- **程序化水墨笔触算法（描述级，实现时细化）**：
  - 每笔 = 一条由落点向画布目标坐标延伸的贝塞尔曲线，宽度随进度随机 4~12px，两端收锋；叠加半透明墨色（`rgba(20,20,20,a)`）+ 轻微晕染（多层低透明度描边）模拟宣纸渗墨。
  - 笔触坐标按「画位索引 → 该画的笔序槽位」映射，使多笔自然构成预设构图（构图用**参数化坐标系**定义，不引用图片）。
  - 成画收尾：在右下角程序化绘制一枚朱红方印（矩形 + 内嵌两字如「墨雨」或用户昵称首字），纯 Canvas。
- **动效**：墨滴命中时一笔「落墨」动画（~150ms）；连击高时笔触颜色略加深或加快生长，强化爽感。

## 四、数据与接口

- **画位配置**（新增，运行期/构建期）：`InkPainting { id, tier, strokes: number, composition: Coord[] }`，`composition` 为参数化坐标序列，纯数据不引用素材。
- **成绩**：复用 `01` REQ-06 的 `gameRecords`（gameId='moyu'）。
- **语料**：字/词层（入门/进阶/挑战），见 `05`。
