# 05 - 数据与素材

**日期**：2026-10-19
**负责成员**：析客
**文档性质**：打字游戏模块的数据与素材约定：语料来源（复用现有六级）、墨雨画位配置（程序化）、诗词射击篇目（公版）、合规声明。
**边界声明**：**不含代码实现**；语料分级体系见 `md/spec/04-词库与语料分级设计.md`；公版判据见 `md/spec/A2-语料来源与许可合规.md`。

---

## 一、背景与目标

本模块**不新建词库**，全部语料复用 `resources/typingMaterials` 与现有构建管线（`scripts/build-typing-dicts.ts`）产出的 `public/dicts/*.json`。墨雨笔触、诗词射击战场、成语接龙轨道均为**程序化生成**，无外部美术素材。需明确各玩法取用的语料层级、难度 tier 映射、以及公版合规边界。

---

## 二、功能需求

### DATA-01 语料复用（不新建）
- 三个玩法全部从现有六级语料取词，通过 `CorpusProvider` / `useWordList` 现有通道，不新增构建产物：
  - **墨雨**：字层（L1）+ 词层（L2），按 tier（入门/进阶/挑战）选取。
  - **诗词射击**：词层（L2）+ 诗句层（L5）+ 文章片段（L6-a/L6-b）。
  - **成语接龙**：成语层（L3）。
- 英语 Tab：墨雨/诗词射击可复用英文单词/段落语料（对码轨纯字母）。

### DATA-02 难度 tier 映射
- 沿用现有难度分组（入门/进阶/挑战，第二批 `spec-20261017-v2` §3 三维定级：字数/文言程度/生僻字密度）。
- 墨雨画位笔数随 tier：入门=简笔（少笔，如 6~10 笔），挑战=繁笔（多笔，如 20~30 笔）。

### DATA-03 墨雨画位配置（程序化，新增数据）
- 新增运行期/构建期数据 `InkPainting { id, tier, strokes, composition: Coord[] }`：
  - `composition` 为**参数化坐标系**中的笔序槽位（如 `[{x,y,w,curve}, ...]`），定义笔触的生长顺序与位置，**不引用任何图片**。
  - 多套构图（山水/竹石/花鸟）纯用坐标定义，由 `02` MOYU-02 的算法渲染。
  - **数量建议**：入门 3 套、进阶 3 套、挑战 3 套（共 9 套起步，纯数据，零素材成本）。

### DATA-04 诗词射击诗句篇目（公版）
- 诗句篇目复用 `A2` §3.5/§3.6 已核验的公版清单（59 条候选，含《静夜思》《春晓》《出塞》等 L5 诗句 + L6 文章片段）。
- Boss 句复用 `A1` 的零声母/ü 密集句素材（爱/安/昂/欧/恩、女/绿/局/学/卷/云）。
- ⚠️ 每篇必须保留 `source` / 公版分水岭（1975-12-31）判定（沿用 `A2` §2 红线）。

### DATA-05 合规声明（强制）
- ❌ 禁止引入任何第三方美术素材（图片/logo/皮肤）→ 墨雨笔触、印章、诗词射击敌人、成语接龙轨道**全部程序化生成**（对齐 `A2` §2.3 美术须自绘）。
- ❌ 成语/诗词释义若引自商业词典则禁止 → 本模块不显示商业释义，或仅用我方原创一句话示例（对齐 `A2` §4.3 + `04` IDIOM-02）。
- ✅ 诗句/成语本身（事实性文本）可用；出处朝代为事实信息可用。

---

## 三、交互 / UI 说明（素材侧）

- 所有视觉元素由 CSS/SVG/Canvas 程序化绘制，无 `public/` 下新增图片资产（合规审查项）。
- 墨雨印章用 Canvas 绘制方印 + 内嵌文字（如「墨雨」），不引用任何字体文件以外的图片。

---

## 四、数据与接口

- 复用：`resources/typingMaterials` 全部字段；`public/dicts/*.json` 现有产物；`useWordList` / `CorpusProvider` 取词通道。
- 新增（数据，非代码）：`InkPainting` 配置（见 DATA-03）；`gameRecords` 表（见 `01` REQ-06）。
- 构建管线：墨雨画位配置作为静态数据随包发布，不进入 `scripts/build-typing-dicts.ts` 的拼音转换流程。

---

## 五、验收标准

- [ ] ACC-D1 三个玩法全部从现有六级语料取词，未新建任何词库或 `public/dicts` 产物。
- [ ] ACC-D2 墨雨画位为参数化坐标数据，渲染为程序化水墨笔触；仓库 `public/` 无新增图片素材。
- [ ] ACC-D3 诗词射击诗句篇目均带 `source`/公版判定，无版权风险。
- [ ] ACC-D4 成语/诗词无商业词典释义引用；需释义处为我方原创或省略。
- [ ] ACC-D5 难度 tier（入门/进阶/挑战）与画位笔数、语料层级映射一致。
