# 01 - 游戏中心与共享引擎

**日期**：2026-10-19
**负责成员**：析客
**文档性质**：打字游戏模块的**壳与共享基础设施**，定义入口、游戏中心页面、三个玩法共用的「下落式街机引擎」与红线合规约束。墨雨/诗词射击/成语接龙的具体玩法见 `02`/`03`/`04`。
**边界声明**：本文档**不含代码实现**；输入双轨机制见基线 `md/spec/02-练习模式与交互设计.md` §1.2 与第二批 `spec-20261017-v2`。

---

## 一、背景与目标

基线 `09-游戏化与激励设计.md` 已规划成语接龙（P1）、ztype 式射击（P2）、异步幽灵对战（P2），但散落在文档各节、且优先级偏低、缺少统一入口与落地形态。需求提出人希望把这些机制整合成一个**可玩的打字游戏模块**，并以「墨雨（Ink Rain）」为视觉招牌新增玩法。

**成功标准**：在 Typing Learner 选择页新增「游戏」二级入口；进入后有清晰的游戏中心卡片页；三个玩法共享一套下落式引擎（落字、锁定、连击、生命、分数、难度曲线）、共享「失败=复盘」；全程遵守 `09` §2 四道红线。

---

## 二、功能需求

### REQ-01 入口：打字模式二级「游戏」
- 在 Typing Learner（打字模式）选择页的二级选项集中，新增第四项「游戏」，与现有 `全拼 / 双拼 / 打字测速` 并列。
- 选中「游戏」后，主区域从「词库/语料选择」切换为「游戏中心卡片页」（见 REQ-02）；语言 Tab（中文/英语）与全局设置保持不变。
- 选中「游戏」时，二级选项的可选项（全拼/双拼/打字测速）收起或置灰；「游戏」自身可带一个下拉用于选择具体玩法，或直接在中心页点卡片进入。
- **边界**：「游戏」是打字模式内的二级入口，**不新增顶层模式**（主理人已确认）。

### REQ-02 游戏中心卡片页
- 页面以卡片网格呈现三个玩法：`墨雨 · 落字成画`（★ 招牌，置顶）、`诗词射击`、`成语接龙`。
- 每张卡片含：玩法名、一句话简介、难度标识（入门/进阶/挑战，复用语料难度 tier）、入口按钮。
- 卡片下方或侧栏展示「本地最佳」成绩（复用 `09` §4.1 段位 + 单局评级，纯本地），**不显示服务端排行榜**。
- 异步幽灵（继承 `09` §3.5）作为覆盖层在各玩法内提供，不在中心页单独成卡。

### REQ-03 共享下落式街机引擎（核心基础设施）
三个玩法共用以下引擎能力（实现时抽为共享组件/模块，避免各自重写）：
- **落字/墨滴生成器**：按难度曲线从语料池取目标，从屏幕上方生成下落对象（字、词、成语或诗句片段）。
- **目标自动锁定**：按当前已输入前缀匹配最靠下的同前缀目标（对齐 Ink Rain「直接开始打字，匹配的词自动锁定」），多目标同前缀时锁定最危险（最接近底线）的一个。
- **逐字/逐词判定**：复用现有双轨输入（对码轨逐字符 / 上屏轨整串），命中即消除该下落对象并推进进度；支持单字级与上屏级两种粒度。
- **连击（Combo）系统**：连续打对累积连击数，分数按连击倍率放大；打错、超时落入、或主动放弃当前目标（Backspace/Esc）则连击归零（不对用户做羞辱性展示）。
- **生命 / HP**：初始 N 条命（如 3~5，按难度）；任一目标触碰底线扣 1 命；命耗尽触发结束→复盘。练习模式（墨雨专属，见 `02`）不消耗生命、不失败。
- **分数与难度曲线**：分数 = Σ（基础分 × 连击倍率 × 难度系数）；难度曲线**靠语料级别升档**（字→词→成语→诗），**不靠提速**（对齐 `09` §1.2 第一原则「准确率优先于速度」与 §3.4 差异化第 3 条）。
- **结束与复盘**：命耗尽或计时耗尽→结束页展示「本局被击落/未完成的词 + 错键热图 + 单局评级 S/A/B/C/D/F（复用 `09` §4.2）」，提供「一键进入弱键强化」入口（对齐 `09` §2.5 不做失败惩罚性展示 + §3.1 弱键强化）。

### REQ-04 双轨输入复用
- 每个玩法提供「对码轨（`code-match`）/ 上屏轨（`ime`）」切换（复用现有双轨），**默认对码轨**（绕过系统 IME，纯键位，与练习一致，且中文/英语单词英文都可玩）。
- 上屏轨用于想用自己输入法打汉字的场景（如诗词射击的诗句、成语接龙的成语），复用第二批 `spec-20261017-v2` 的 `ime` 上屏轨口径（字/分 + 字准确率 + 回改，不显示 WPM）。
- **约束**：两轨指标分开记录、分开标注、不混算（沿用 `06` §3 机会 7 口径纪律）。

### REQ-05 红线合规（强制）
本模块全部玩法遵守 `09` §2 四道红线 + §2.5：
- ❌ 无金币/钻石/皮肤/体力/抽卡；❌ 无赛季/通行证；❌ 无「累计 X 小时升 Lv」时长等级；❌ 无付费墙（全功能免费、无广告）；❌ 无失败羞辱性展示（改为复盘）。
- ✅ 激励只走 `09` 已规划的：段位（击键 6/8/10）、单局评级 S/A/B/C/D/F、证书（纯前端 Canvas PNG）、streak、每日挑战、成就——且这些由 `09` 统一负责，本模块不另立激励体系。

### REQ-06 成绩记录（复用 Dexie）
- 单局成绩（玩法、轨、语料 tier、分数、准确率、击键、连击峰值、评级、时间戳）写入现有 Dexie（建议新增轻量 `gameRecords` 表或复用 `chapterRecords` 扩展字段），**纯本地、零上传**。
- 幽灵数据（逐字时间戳曲线）本地存储，复用 `09` §3.5 异步幽灵方案；**同轨同口径**，禁止跨轨对战。

## 三、交互 / UI 说明

- **选择页二级栏**：`[全拼][双拼][打字测速][游戏]`，「游戏」激活时进入中心页；选中后 URL 参数建议带 `?mode=game`（复用第二批 Typing Learner 的 URL 参数约定）。
- **游戏中心页**：卡片网格 + 本地最佳成绩条；点击卡片 → 玩法内页。
- **玩法内页共用布局**：上方状态条（分数 / 连击 / 生命 / 倒计时或纸数）；中央游戏区（落字区 + 墨雨画布 / 射击战场 / 接龙轨道）；底部复用现有 `TypingKeyboard` 键位图（可选显示，练习时高亮当前目标键，对齐第二批键盘组件）。
- **复盘页**：复用 `09` §2.5 + §4.2 的「失败不羞辱」框架，展示被击落词 + 错键热图 + 一键弱键强化。

## 四、数据与接口

- **游戏配置类型**（新增，运行期）：`GameConfig { id, name, kind: 'moyu'|'shoot'|'idiom', languageTab, defaultTrack, difficultyTier }`。
- **成绩记录结构**（新增 `gameRecords` 或扩展）：`{ id, gameId, track, language, tier, score, accuracy, kps, maxCombo, rating, timestamp, ghost? }`。
- **语料来源**：全部来自 `resources/typingMaterials` 六层（字/词/成语/诗/文），通过现有 `useWordList` / `CorpusProvider` 通道取词，不新建词库（详见 `05`）。
