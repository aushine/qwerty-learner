## 📌 TL;DR

基线 `09-游戏化与激励设计.md` 已规划了若干游戏化机制（成语接龙 P1、ztype 式射击 P2、异步幽灵对战 P2），但分散在文档各节、且多为 P2。**本批次第一次把这些机制整合成一个可玩的「打字游戏模块」，并以用户点名的「墨雨（Ink Rain）」作为视觉招牌新增玩法。** 三条关键决策（已与需求提出人确认）：

1. **模块范围**：游戏中心 = 墨雨·落字成画 + 诗词射击 + 成语接龙（整合交付，不再分散排期）。
2. **入口位置**：在**打字模式的选择页**新增「游戏」二级入口（与 全拼 / 双拼 / 打字测速 并列），不新增顶层模式。
3. **墨雨素材**：**程序化水墨笔触（Canvas/SVG 程序生成）**，零外部素材许可风险，契合基线 `A2` §2.3「美术须自绘」红线。

## 6. 术语表

| 术语 | 定义 |
|---|---|
| **打字游戏模块 / 游戏中心** | 本批次新增的独立模块，聚合墨雨·落字成画、诗词射击、成语接龙三个玩法 + 异步幽灵覆盖层 |
| **墨雨 · 落字成画** | 招牌新玩法：文字如墨滴下落，逐字打出→程序化生成水墨笔触，成画奖励（参考 Ink Rain / 墨雨） |
| **落字 / 墨滴** | 游戏中从屏幕上方下落、需在触碰「纸面/底线」前打出的字符或词 |
| **程序化水墨笔触** | 用 Canvas/SVG 算法生成的毛笔笔触与晕染效果，非引用任何外部图片素材 |
| **连击（Combo）** | 连续打对累积的倍率；打错或放弃当前词则断连击（对齐 Ink Rain 与 `09` §3.2 节奏玩法） |
| **复盘** | 游戏结束（生命耗尽）时不显示「你太弱了」，而是展示「本局被击落的词 + 错键热图」，对齐 `09` §2.5 |
| **打字模式二级「游戏」** | 在 Typing Learner 选择页与 全拼/双拼/打字测速 并列的第四项二级入口 |
