# 03 - 诗词射击（引用 09§3.4）

**日期**：2026-10-19
**负责成员**：析客
**文档性质**：**继承** 基线 `09-游戏化与激励设计.md` §3.4「ztype 式射击模式」并**提级整合**为打字游戏模块子玩法。本文件只写「增量落地」与冲突裁定，核心规则以引用基线为主（遵循本目录 `README` §4.5 引用优于复制）。
**边界声明**：**不含代码实现**；落字/锁定/连击/生命/复盘见 `01` REQ-03；双轨见 `01` REQ-04；红线见 `01` REQ-05。

---

## 一、背景与目标

基线 `09` §3.4 已完整设计 ztype 式射击（敌舰带词标签、击毁后诗句逐字显现、三类敌人、波次靠语料升级加压、失败=复盘），但列为 **P2** 且缺少落地形态。本批次将其**提级整合**进游戏中心，作为「诗词射击」玩法落地。

**成功标准**：诗词射击可玩；三类敌人（常规/护盾/ Boss）对应真实技术难点；击毁后诗句逐字显现、通关呈现全诗+作者+朝代；失败页为复盘。

---

## 二、功能需求（增量，引用基线为主）

### SHOOT-01 继承基线 §3.4 的核心设计（引用，不重写）
- 敌舰/下落对象带词标签；打完即击毁；波次递进；连击；音效（复用现有 `useKeySounds` / `useHintSounds`）。
- 差异化第 1 条：敌舰标签是「诗句中的词」，击毁后诗句逐字显现，通关后完整呈现全诗 + 作者 + 朝代（呼应 `06` §4.3 H-4，依赖 `A2` §3.5/§3.6 公版篇目）。
- 差异化第 3 条：波次靠「语料级别升档」加压（字→词→成语→诗），**速度保持用户自选**（对齐 `09` §1.2 第一原则）。
- 差异化第 4 条：失败不惩罚，改为「被击落词 + 错键热图」复盘（对齐 `09` §2.5）。

### SHOOT-02 三类敌人（继承 §3.4 第 2 条，本批次细化取值）
- **常规舰** = 普通词语（练速度）。
- **护盾舰** = 含易错韵母的词（in/ing、iang/uang、iao/ai，取自 `A1` §4.3 的 8 组高频易错对照）（练精度）。
- **Boss** = 零声母音节密集句（爱/安/昂/欧/恩）或 ü 系列字（女/绿/局/学/卷/云，取自 `A1` §3.3）（练最难点）。

### SHOOT-03 本批次落地形态（增量）
- 入口：游戏中心卡片 → 诗词射击内页（复用 `01` REQ-03 共享引擎）。
- 语料：诗句取自 `A2` §3.5/§3.6 公版篇目（L5 诗句 + L6 文章片段），词层取自 `typingMaterials`；详见 `05`。
- 双轨：复用 `01` REQ-04（默认对码轨；诗词上屏用 `ime` 轨）。
- 单局结算：复用 `09` §4.2 S/A/B/C/D/F 多维评级（准确率一票否决）。

## 三、交互 / UI 说明

- 复用 `01` REQ-03 布局：落字区为「战场」，诗词显现条在上方/侧栏随击毁增长；命耗尽→复盘。
- 三类敌人有视觉区分（颜色/图标），但**不引入任何外部美术素材**（对齐 `A2` §2.3 + `02` MOYU-06 程序化风格），用 CSS/SVG 几何区分即可。

- [ ] ACC-S1 诗词射击可玩：下落词带标签、打完击毁、连击与音效正常。
- [ ] ACC-S2 击毁后诗句逐字显现，通关呈现全诗 + 作者 + 朝代。
